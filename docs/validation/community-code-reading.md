# Community and solution code reading

Fenced code in solutions, posts and comments now has an independent **Wrap lines** toggle. It starts off so indentation and deliberate line breaks remain visible. Wrapping changes presentation only; copying always uses the original snippet, including Unicode, tabs and whitespace. The preference survives locale changes and asynchronous syntax highlighting, and resets for a replaced snippet or language. Inline code keeps its existing rendering.

The copy command preserves a focused native button while busy and ignores rapid duplicate commands. An eight-second deadline releases a clipboard request that never settles. Missing support, synchronous exceptions, rejected permissions and timeouts show a labelled, read-only manual-copy field. Focusing that field selects the snippet for the platform's normal copy shortcut or menu. Failure does not focus the field automatically. Locale changes preserve its DOM node, selection and scroll. A retry can finish independently of an older timed-out request; later acknowledgements cannot overwrite a new snippet, route or unmounted reader. Retired deadlines and history listeners are cleaned up. A delayed history notification for the already current URL cannot cancel a newer explicit copy. A native clipboard operation already handed to the browser cannot be cancelled by the application; its late UI acknowledgement is ignored.

The toolbar wraps within narrow cards. Buttons use the existing 15px supporting text scale with 40px targets, increased to 44px for coarse pointers, visible keyboard focus and a pressed state for wrapping. Syntax colours and the existing code font/size are retained. Additional styles are imported with the deferred community Markdown component, rather than the initial application shell. No dependency, route schema, practice source, account storage, database, runtime or judge contract changes are required.

`check-community-code-block.mjs` mounts the real Markdown renderer and asynchronous syntax highlighter in JSDOM. It covers per-snippet wrapping, exact clipboard payloads, duplicate/busy behavior, bilingual feedback, denied/missing/synchronous/never-settling clipboard cases, manual selection continuity, retries, code/language/A→B→A replacement, route/history/unmount isolation and resource cleanup. It also opens the actual in-place solution reader, verifies code controls leave the disclosure open, checks Escape inside the manual field and returns to the existing practice editor without changing its code/caret or pane scroll. Existing solution, profile, Markdown/security and frontend suites remain in place. Both edition builds and emitted CSS/dependency graph checks supplement those behavior checks. These are source/DOM/build checks, not browser rendering, layout or hit-testing verification.

GitHub workflows remain manually disabled. This wave creates no CI run, release tag, deployment or production application write.
