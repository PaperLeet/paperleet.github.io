# Inline reading of source experiences

Frequent-concept and company-comparison source cards now use the existing community reader. The compact 140-character preview reports code, formula and table content even when no prose can be extracted. Explicitly expanding a card renders its original Markdown, code controls, formulas, tables and local outline without opening a separate post or requesting another source response. Reading controls and excerpts use the shared readable typography.

The same source-card renderer serves problem workspaces and company-filtered library rows. Source links keep their existing canonical public return scopes and workspace/library new-tab behavior. Anonymous identities and visible affiliation still come from the existing strictly validated public feed. Rendering retains the community Markdown safety rules and provides the existing raw-text fallback if formatting fails. External body content is absent from collapsed summaries.

Escape collapses the nearest active reading layer: expanded long code first, then the current source body, then the source panel. Manual-copy and other editable fields retain their native Escape behavior across all source hosts. The frequent-concept source panel also has a bottom close action. Closing returns focus to the corresponding source toggle and reveals it only when covered, using the shared viewport helper. A stale close from a different route cannot move focus or close the prior scope. Owner changes and unresolved account boundaries still retire readers and abort outstanding requests. Collapsing a source panel preserves the existing abort-and-fresh-explicit-reopen contract; this change adds no shared cache.

Validation includes React/JSDOM StrictMode with code-only, formula-only, table and unsafe-HTML fixtures; nested Escape, controlled unavailable clipboard/manual field, safe Markdown, anonymous affiliation, locale continuity, stale-route close, abort/owner isolation and an unchanged mounted private editor, selection, direction, scroll and session draft. The actual problem workspace suite also exercises formatted source reading and native Escape in its manual-copy field. An additional disposable JudgeHandler/SQLite flow renders three real public source reports from two verified synthetic authors, including an anonymous report, and verifies that reader actions add no source request or database write. Existing source-return, library and comparison flows remain part of full application qualification.

Four build variants must preserve the existing initial-script byte budgets, deferred source-preview/rich-reader graph, catalog math and static-route checks. There are no catalog, algorithm, judge, dependency, API or schema changes. Existing numerical execution evidence remains attributed to its original execution commits; only file/tree/archive identities are checked here.

Limits: these checks do not prove physical layout, native focus/select/IME/clipboard or real identity-provider behavior. Controlled viewport rectangles and a deliberately unavailable clipboard exercise the corresponding code paths; no OS clipboard or browser automation is used. This wave does not deploy or dispatch CI.
