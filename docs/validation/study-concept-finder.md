# Search the study handbook without replacing its reader

The handbook concept picker now searches loaded public Chinese/English titles, module IDs, question numbers and required function names. Queries are bounded to200 Unicode code points, width-normalized with NFKC, lowercased and matched as literal whitespace-separated AND terms. Results retain the offered curriculum/catalog order. No hint text is imported or searched, no request is made and no query enters the report URL, a practice return, storage or publication data.

Typing leaves the applied candidate list unchanged until submission; clearing follows the shared search control's existing behavior. The native select retains the current concept in a separate Currently reading group whenever a filter excludes it, with actual matching candidates grouped separately and an accurate status message. Zero matches disables the chooser while retaining its current option and readable guide. Existing hints stay open until the learner explicitly chooses another concept; only that choice changes the guide/import and its canonical practice/sign-in destination. Clear/Escape restores candidates with native search focus. Single-concept views omit the redundant search field.

The picker is keyed by the canonical source scope and related/current range, so a new company/role/path/source or range starts with a fresh local query. Locale and equivalent progress renders retain the native field, selection, horizontal scroll and applied search. Search remains inside the existing role/path availability rules. The learner editor, draft, selection direction, scroll position, actual page URL, grade and notes unlocking remain untouched.

`PreparationConceptPicker` owns local query state separately from its sibling reader. The matcher reads only loaded metadata. The shared `CommunitySearch` still provides the existing IME/legacy-Enter, Unicode limits and explicit clear/submit handling. Its11 existing style rules, including mobile/coarse-pointer rules, move unchanged from shell community CSS to a stylesheet imported by that component. This gives consumers direct style ownership and keeps optional search styles deferred. The picker has a bounded responsive grid, body-sized native choice text,44px selection target, readable status text and visible keyboard focus. No dependency or initial asset budget is added or relaxed.

The mounted handbook fixture preserves all earlier assertions and adds bilingual/ID/number/function matching, literal regex-looking terms, Unicode width/combining characters, immutable metadata, submit-before-filter, current-reader grouping, zero-result recovery, Escape focus, native descriptions, exact open-hint/editor/caret/scroll/storage/URL continuity, locale/progress continuity, explicit deferred selection, canonical practice/login source, role/path scoping, source-query retirement and single/empty catalog states.
