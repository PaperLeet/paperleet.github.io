# Fast browser syntax feedback — 2026-10-14

Previously, a syntax error in Flow Matching waited for complete reference/mutant training calibration before the learner's code was compiled. The browser now checks syntax immediately after Python initialization, before loading numerical/testing packages. Valid code still receives the complete unchanged calibration and suite.

## Behavior

- A standalone CPython compilation step catches SyntaxError, IndentationError and TabError without executing imports, loops, raises or other learner statements.
- Syntax feedback is a distinct protocol outcome, carrying only a bounded diagnostic and the client-captured source. It creates no report, test counts, pass, account grade or automatic server job. Frame/nonce validation and cleanup apply to this outcome as well.
- The editor displays native Python line/column positions and distinguishes current diagnostics from those for earlier source. The notice changes to a status message after editing. Starting a new run clears the old diagnostic; module and owner boundaries retain their existing isolation.
- The Tests tab uses an attention indicator for current syntax errors or older-source results; a green indicator requires a current-source passing report.
- A syntax failure preserves the earlier report and accepted progress. An earlier pass is labeled as such while the current source differs. Numerical runtime calibration metadata is removed from the syntax result so it cannot imply that this run completed calibration.
- The loading sequence adds a syntax step; older workers that omit it remain accepted. Runtime/learner hard caps and cancellation behavior are unchanged.
- Hosted Chinese/English running instructions now recognize the headings generated by the exporter. They explain immediate guest browser runs, explicit draft import and server-authoritative account progress.

## Evidence

- `cd web && npm run check`: passed. The syntax check compiles 268 actual maintained starters, reference implementations and mutants. Separate sources containing an unconditional raise, an infinite loop and a missing import demonstrate compile-only execution. Error classes/locations, malformed protocol messages, escaped display content, source versions, bilingual notices and frame cleanup are checked.
- `cd web && npm run build`: passed TypeScript and the initial graph budget; 369,954 bytes raw / 118,498 bytes gzip. Heavy editor, rendering, community/account and lab code remain deferred.
- Real in-app browser, disposable localhost production build: Flow Matching's invalid syntax returned **line 1, column 12** in approximately **3.09 seconds** on the tested cold origin. Request logs contained **zero wheel downloads** and **zero server judge submissions**. Neither the reference nor any mutant training ran. This is one observed UI run, not a cross-device latency benchmark.
- The fresh error view displayed only syntax feedback, without a fabricated 0/0 test report or pass state. After editing, it said the error belonged to earlier source. Navigating through the paper library to Schedules showed no Flow Matching diagnostic.
- Schedules then completed genuine browser calibration (**8 reference tests, 5 mutants**) and passed **8/8**. A subsequent syntax error at **line 34, column 9** preserved that history as **Previous tests passed**, with a changed-source notice. Restoring and rerunning the implementation cleared the syntax notice and again completed calibration and **8/8** tests.
- At 390 × 844, the syntax notice, line/column, prior-result label and source-version explanation remained readable in the stacked workspace.
- A separate hosted-style loopback environment allowed a signed-out guest to receive **IndentationError at line 2, column 1** without a sign-in prompt or server job. Both Chinese and English description panels showed the corrected browser/draft/account instructions.

No Python adapter, maintained problem, calibration threshold or experiment was changed. Browser coverage remains 44/60 modules. Diagnostic text is tab-memory feedback, never an authoritative account result. Production deployment and additional browser/device coverage were not performed.
