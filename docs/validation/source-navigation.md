# Source-bound error navigation

Syntax feedback previously displayed a line/column without moving the editor. Failed-test tracebacks likewise required manually finding the learner line. The new bilingual action opens the code panel and moves the cursor only after an explicit click. CodeMirror and the existing plain-text fallback both support it.

Syntax navigation requires identical captured source. Report navigation requires the existing SHA-256 source match and a bounded explicit pytest learner frame; it selects the deepest matching frame. Native implementation paths and browser/hosted `submission.py` are supported. Tests, reference implementations, numerical adapter frames, ambiguous local basenames and unverifiable/changed reports have no shortcut. A traceback string is advisory, not trusted executable metadata. No file path becomes a URL or filesystem operation.

Requests are scoped to owner, module and source, discarded on a scope change, and consumed after focus. Repeated clicks create fresh requests; reopening the lab or ordinary editor rerenders do not replay a consumed request. Python Unicode columns are converted to UTF-16 offsets, line endings normalized, EOF positions bounded and oversized columns clamped to the line end. Navigation never edits source, establishes a pass or changes numerical tolerances.
