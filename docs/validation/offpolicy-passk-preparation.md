It is available for LLM and research preparation. Existing company resources, report counts, frequency evidence and all fifteen prior paths are retained. This is a learning sequence, not a claim about questions asked by any company.

Two new guides add six bilingual explain/implement/verify prompts. Their function, shape, dtype, reduction and gradient boundaries follow the maintained exercise READMEs, notes, reference functions and tests. There are now **69 guides / 207 prompts / 16 paths**, with all twelve current RL exercises covered. The original 67 guide objects remain unchanged. Larger prompt content and curriculum metadata remain deferred; the initial route allowlist adds only the new path ID.
