# Representation and contrastive preparation

Add a curated path for ML and research roles: CLIP, SimCLR, MoCo, VICReg and I-JEPA. Each module has three bilingual study prompts covering explanation, implementation and verification, bringing the shared handbook to 32 guides and 96 prompts. The sequence compares paired cross-modal retrieval, in-batch contrast, historical negative queues, feature regularization and masked latent prediction.

Content is grounded in each existing exercise README and its exact required function list. It preserves exercise-specific scales, zero-vector conventions, gradient boundaries, input immutability and teaching scope. The existing module pages retain the underlying paper and implementation references. In particular, the [pinned I-JEPA training code](https://github.com/facebookresearch/ijepa/blob/52c1ae95d05f743e000e8f10a1f3a79b10cff048/src/train.py) uses feature-axis normalization, smooth-L1 loss and the momentum target update; these prompts follow that exercise contract.

The path uses the existing role-aware UI, learning progress, handbook import and source/practice/login returns. Its track is accepted by the existing validated interview URL parser. Guides remain deferred until opened. Community contribution counts and company evidence continue to come from published reports.

Validation: shared catalog pytest, guide/readme/function contracts, actual handbook selection and all five prompt loads, precise track/company/role/stage/saved/practice/sign-in returns, and the actual ML preparation-path entrance. Complete frontend checks, strict local/hosted builds and real HTTP integration are required before publication. DOM checks do not claim browser visual review.
