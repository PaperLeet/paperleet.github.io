# Resume a collapsed comment draft at its writing position

Collapsing a feed card's comments unloaded its editor. The shared draft text came back on reopening, but the selection and textarea scroll position reset. The card now retains one transient editor-view snapshot, scoped to that mounted account/post/card instance. It includes the exact draft value, UTF-16 selection offsets and direction, and vertical/horizontal textarea scroll. Closing comments still releases their editor DOM.

The shared Markdown editor optionally records its view when unmounting. Preview mode records the last visible writing position, with an exact-value guard. The card restores a matching snapshot after the editor is visible again, including after a minimized composer or a same-owner account check. A different draft discards stale offsets; changing the account replaces the owning card and snapshot. Separate cards for the same post retain independent positions. A small editor-instance token distinguishes an actual remount from Strict Mode effect replay without retaining an old DOM subtree. Snapshots do not survive card removal or reload and add no draft-storage fields.

Opening comments for reading leaves focus on its existing trigger. Explicitly returning to writing uses the existing opener/route guard, then restores the input position. Restoration adds no focus, navigation, social request, storage write, publication or grading behavior. Existing comment-read cancellation, owner checks, publication receipts and newer-focus protections remain intact. Markdown format/preview/undo retains the corresponding horizontal scroll and selection direction where applicable.

The added UI regression fails on the prior implementation with selection start 0 instead of 3. It checks Unicode offsets, backward/forward selections, both collapse controls, precise scrolling, preview/write and minimized-composer return, replacement shared drafts, same-owner checks, account replacement and independent duplicate cards. A separate Strict Mode regression caught a replay snapshot overriding a newer selection (2 instead of 5); the instance guard preserves the newer intent. Existing card and shared-editor checks still apply, as do the complete frontend checks and local/hosted build budgets. React/HTTP verification is distinct from browser visual QA; synthetic test records are restricted to temporary local databases.
