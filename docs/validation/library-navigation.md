# Library filters and return context

Library filters previously lived only in PaperLibrary state, and the paper-detail return link always opened the full library. Opening a paper or returning through practice lost the search/collection context. The new route helpers encode all six public filter fields in a local hash URL. Filter changes replace the current history entry without resetting scroll; normal page navigation adds its usual entries. Unicode and reserved search characters remain query data.

Library paper links, paper-detail module links, previous/next controls, practice recommendations and sign-in continuations carry a canonical library-only `from` value. App looks up the module by the path before the query, including asynchronous result/syntax feedback, code-location focus and editor-reload guards. Statistics refresh also keys on the path so each typed query character does not refetch aggregates. A module completed during practice can disappear from an unchanged Not started filter on return; this reflects the current workspace rather than stale results.

Return context accepts only known library scopes, bounded text, supported filter enums and one occurrence of each allowed parameter. It rejects external/recursive return targets, unknown fields and invalid shapes. Retired categories/topics normalize to visible defaults. Shared links contain no owner, draft, report or acceptance data; status results depend on the active workspace. Legacy learning-list URLs still resolve to their collection. Pending progress displays a checking state rather than fabricated empty/unsolved status-filter results.

Position recovery is a deferred enhancement. It keeps at most eight canonical public view positions in tab session storage, with an in-document memory fallback. It remembers the selected paper and its viewport offset so a shuffle on refresh does not substitute an unrelated row at the same pixel. Stale async imports/timers cannot act on another view; loading/status filters wait until their rows are available. The selected collection is revealed horizontally without scrolling the whole window up to its carousel. A failed optional position import leaves filters and return links usable.
