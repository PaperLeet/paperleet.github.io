# Company and publication-period continuity in practice evidence

Opening an exercise from a company-filtered library or interview list seeds the
practice experience preview with that list's known company and publication
period. A compact source label makes these inherited controls explicit; the
collapsed preview button names its selected company. Users can explore another
company or period, then restore those two controls together. Restoration focuses
the stable publication-period select before its temporary button disappears.

Only the validated practice return link's company and days are inherited. Search,
saved membership, role, stage, outcomes and other list controls remain in the
return URL and are not sent as implicit preview filters. Top company chips still
show public evidence across companies for the selected publication period. The
source preview applies its explicit company selector. Counts remain community
report/contributor evidence, not claims about actual interview frequency.

The route subscription belongs to the account boundary. Changing the inherited
company or period remounts only the evidence panel; opening state from an old
route is retired. Default routes retain the prior all-company/past-year behavior.
Unknown companies, malformed/external/recursive returns and a different exercise
cannot seed the controls. No preference or draft storage is added. Report bodies
load only after an explicit preview action.

The actual React/JSDOM evidence suite checks hash and path routing, public-only
projection, inherited controls and source links, cancellation/restoration, native
focus after the restore button disappears, locale/owner/route boundaries, and
unchanged private editor DOM/source/selection/both scroll axes/storage. Its real
HTTP fixture uses anonymous loopback JudgeHandler and disposable SQLite to read
a company/90-day origin and then all-time reports. No UI mutations, production
writes, numerical execution or physical-browser layout verification are claimed.
