# Community search and bounded feed recovery

The feed keeps its compact search/sort group and existing reading-list fallback. Search editing now belongs to a module-scope `CommunitySearch` component, so typing an unapplied query does not rerender the post list or composer. Clear and Escape return focus synchronously to the native search input. Cancelling an unapplied query leaves the current URL and page alone; removing an applied query uses the existing canonical route with page one while retaining board, topic, saved/following scope and ordering.

Input accepts up to 200 Unicode characters, matching the existing route/API limit. A native 400 UTF-16-unit cap allows 200 supplementary-plane characters; React bounds committed text to 200 code points, and an associated hidden hint describes the actual limit and keys. Control characters become spaces only on submission. Composition remains editable until commit. IME Enter, including the legacy keyCode 229 path, cannot also apply the search; native candidate confirmation is not prevented. Escape leaves an active composition alone. External applied-search changes and the parent's existing owner/topic key discard stale local input state. These are DOM event checks, not a claim about manual testing of every OS input method.

The feed now has a 20-second read deadline. Timeout aborts the transport and presents a translated, retryable error even if a transport ignores abort. Error ownership includes the exact request scope. Retries preserve canonical filters, current unapplied search text and the open composer, including its working body, selection direction and both scroll offsets. Success, error, route/account changes and unmount clear the deadline; expired, cancelled and settled callbacks cannot overwrite a newer view. Guest/private capability gates start neither requests nor deadlines. Locale changes translate timeout feedback without refetching.

Search actions have 40 px desktop targets and 44 px coarse-pointer targets with inset focus rings. The form and sort select align at 44 px normally and 48 px on coarse pointers. The group wraps when controls would compress the input excessively. Search text retains the shared 17 px body scale. Native duplicate search decorations are suppressed; no extra count/description row, dependency, font download, animation or new API/storage format is introduced.

Verification covers mounted search and actual feed/composer flows, the existing compact discovery/navigation tests, complete frontend checks and both edition builds under the existing bundle budgets. Compiled CSS checks establish declarations and bundle boundaries; browser rendering, hit testing and clipboard/OS UI are not claimed. This is frontend behavior on existing account/community APIs. The private backend, exercise/runtime source and published browser payloads remain unchanged; the earlier MoCo full-suite warning remains a separate release follow-up.

Ordinary commits do not dispatch CI or deploy. The reviewed release-only workflows remain inherited unchanged; production publication waits for the user's explicit release.
