# Company library row evidence and account actions

Company-filtered exercise rows show the selected company's distinct contributor and public report counts. These are summary snapshots for the selected publication period, not measured interview frequency. A compact action row replaces the longer implementation-goal subtitle once its optional enhancement loads; ordinary paper/course rows and their native exercise links remain available unchanged. Incoming numbered browsing, inline paper tags, incremental twenty-row batches and restored list windows are preserved. Adding a batch retains an existing row’s anchor, action controls and open source panel without new source or bookmark reads. For a retained row, the original anchor stays mounted and contains no action buttons or nested anchors.

Sources open inline only after an explicit click. The shared source reader requests at most three public experiences for the exact company, publication period and concept. Library search/difficulty/progress apply to exercises and never become report-body filters. Local filtering or language changes retain a still-visible row's disclosure and reuse its source data. Changed company/period/account generations retire the preview and abort old reads. Bad, duplicated, wrong-company or wrong-concept data never renders as a valid empty result; genuine empty results describe possible edits/removal. Explicit retry and modifier/composition-safe Escape preserve the user's current focus intent. Full posts, complete-source links and source metadata facets open new tabs with noopener/noreferrer, preserving the original filtered list. Anonymous authors remain anonymous while public affiliation stays visible.

Row saves reuse the existing account bookmark service and shared owner-specific store. Supported signed-in rows coalesce their initial private snapshot into one read. Only an explicit save/remove writes; an uncertain response retains its captured direction for retry instead of reversing it. Account checks, unsupported capabilities and guest sign-in returns remain explicit. The existing private-study-list button remains available when its separate capability is supported. No source read, filter, locale change or bookmark action writes learner drafts, grades or judge runs.

The filter, company-status and row-action views share one deferred feature boundary. Company metadata, source reading and private saving remain deferred, under the unchanged three-asset/400 KiB raw/130 KiB gzip shell budget. Small optional controls share the existing in-place retry button; these retry controls do not reload the workspace. The App also parses its library return once per render instead of once for every collection candidate and again for practice selection.
