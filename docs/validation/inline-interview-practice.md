# Inline interview report practice

Report cards show two linked concepts initially. A local expand/collapse action replaces the former count link to the full discussion. All linked concepts remain in source order, up to the existing twelve-concept publication limit. Returning from an additional practice concept reveals its original entry before the existing controller measures and restores focus; the expansion stays mounted if a newer focus cancels the parent restoration. A manually collapsed return remains collapsed. Available practice links retain the precise interview/company/search/saved-list/page return context and the existing reading-position attributes.

Unavailable catalog entries stay visible as labelled, non-link items. Pending details are distinguished from unavailable practice; a catalog failure exposes the existing explicit catalog retry callback. Cached practice remains usable. A stable logical item retains focus as catalog details arrive. An explicit successful retry can focus the recovered item, yielding to a newer focus or route. No automatic social requests, new storage, publications or practice runs are introduced by expansion.

Keyboard expansion focuses the first additional concept; pointer expansion keeps its control focused. Collapse returns a removed focused item to the surviving toggle. Controls and regions have unique instance IDs, bilingual labels and coarse-pointer targets. Anonymous affiliation, inline comment composition and bookmarking use the existing shared components.

Validation: `node scripts/check-interview-report-practice.mjs` mounts actual report cards and checks expansion, source URLs, actual list/practice reading round trips including the third concept, focus/route guards, missing and recovered catalogs, explicit retry, anonymous affiliation, separate card instances and unchanged storage. Existing interview saved-list, reading-return and full frontend checks cover integration. TypeScript and both production build configurations are required. These DOM tests do not claim browser visual review.
