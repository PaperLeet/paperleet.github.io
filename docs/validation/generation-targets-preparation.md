# Generation targets and gradients preparation

The new **生成目标与梯度 / Generation targets & gradients** path connects `diffusion/param_conversion`, `diffusion/flow_matching`, `diffusion/jit` and `diffusion/drifting` for ML and research preparation. Two new bilingual guides add six explanation/implementation/verification prompts, bringing the handbook to 71 guides and 213 prompts across 17 paths. The prior 69 guide objects and 16 path objects remain unchanged. Company associations, observed frequencies, reports and official resource lists are unchanged; this is a curated study path, not evidence that a company asked these questions.

JiT prompts distinguish network output from loss space and contrast a linear-path time derivative with the existing rotation-angle parameterization. Local contracts cover `[B]` time broadcasting, floating precision, x/noise/v conversion, the clamped x-target shared by all branches, mean reduction and preserved input/target gradients. At clipped endpoints a perfect physical prediction need not have zero loss in every branch. The authored scalar example gives loss 4/9 and prediction gradient −16/9; the same clean-prediction error at t=.8 versus .2 has a 16× loss ratio. The guide does not infer image-model results from the reduced toy.

Drifting prompts distinguish one-pass inference from iterative training, standalone differentiable fields from frozen training targets, and scalar loss values from their intended gradients. They follow the maintained toy’s Euclidean kernel, self-mask, row/column masses and cross-group coefficients. The exercise uses log-domain normalization, intentionally differing from the pinned notebook’s absolute product floor. A new independent example uses generated `[0,2]`, positive `[1]`, temperature `1/ln2`: field `[−1/3,1/3]`, loss `1/9` and generated gradient `[1/3,−1/3]`. A field-only detach counterexample has the same value but cancelled generated gradients. Singleton, distant-kernel and invalid-input cases remain explicit local contracts.
