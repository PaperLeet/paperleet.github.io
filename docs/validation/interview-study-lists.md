# Save interview practice batches to private account lists

Company, frequency and comparison practice groups expose an expandable **Save to a private list** action. The complete public catalog batch and its order are captured before writing. Users can create a named list atomically or append only the missing modules to an existing list, keeping its original positions. The list remains private and independent of code, graded attempts, bookmarks and public reports.

The private list interface and store load on the first explicit expansion. Closing retains the native name input and selection. Escape respects composition and native selects; route, account and batch changes retire the old editor. Guests get a sign-in continuation for the canonical public batch; unsupported services do not request lists.

A successful save is attributed to its exact request receipt, never another widget's shared mutation. Ambiguous transport retries the original command; revision conflicts require an explicit latest read and resubmission. Newer text and current editor focus survive completion. Confirmed identical saves are disabled; a changed title or destination is a new explicit intent. Deleted destinations remain visibly unavailable until the user chooses another.
