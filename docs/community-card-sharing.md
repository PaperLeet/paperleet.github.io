# Share posts and comments from their feed

Community post cards and interview-report cards expose a named, native Copy link action beside the existing like, comments and report controls. Each visible inline comment exposes its own reply link copy action without duplicating the existing View in discussion link. Sharing remains a local clipboard action: it never records a repost, opens the thread, changes filters, fetches data, publishes a reply or mutates practice history.

The shared DiscussionLink component keeps its established full-thread behavior by default. The compact feed variant uses44px targets, theme-aware hover/focus/disabled styles and a full-width recovery row when manual copying is needed. Successful copy and failures are announced. Denied, missing or timed-out clipboard APIs expose the complete read-only URL for explicit manual selection; late replies never replace an already offered recovery. Locale changes preserve native control and manual-input identity, selection and scroll.

Copied URLs carry only a validated public post ID and optional reply ID. Credentials, current server query parameters, return-to/search/owner/favorites scope, comment drafts and code are excluded. URL construction uses the installed public router: hash/subdirectory editions keep their base path, and native-path pages share the router-canonical public discussion destination. Anonymous comment copy labels use Anonymous rather than a hidden display name; existing affiliation display is retained.

Copy begins only from the current, connected, visible card and outside account checking. Account changes or checking retire local copy feedback. A newer filter/render supplies a fresh view guard so retained cards stay actionable; stale pre-render callbacks refuse copying. Inline comment copying reuses already loaded replies, and delayed completion never claims focus or touches the draft editor.

Actual React/StrictMode checks exercise the real Community feed, InterviewReportCard and inline comment controls: precise post/reply URLs; duplicate-click protection; clipboard success, denial, absence and timeout; localized identity and manual selection; current/hidden/stale/account/guest/updated-scope/unmount behavior; anonymous accessible names and affiliations; preserved real comment drafts and private code/caret/scroll; no API mutations; and installed path-router continuity. Existing full-thread sharing, card commenting and quoting/editing regressions remain separate checks. Physical browser geometry and native clipboard permission behavior are not established by JSDOM.

The disposable real-HTTP flow reads two anonymous posts and both comment previews through JudgeHandler/CommunityService, then copies exact public post/reply destinations into a controlled clipboard and exercises manual fallback. It compares the entire SQLite projection before and after; reactions, bookmarks, replies and practice state remain unchanged.
