# 实现提示

建议先独立完成练习，再查看本页。

从 `memory.detach()` 取候选，点积后减去固定 `log_z` 和噪声先验的对数。在对数域用 softplus 保持稳定；K 个噪声项求和，再对 B 个查询求平均。不能把 `K/N` 改为 `1/N`，也不能忽略 Z；整体平移模型对数似然会改变 binary NCE。记忆更新返回独立、脱离梯度的副本。

查询 `[B,D]`、记忆 `[N,D]`、候选 int64 `[B,K+1]`，K≥1；浮点数据有限且 dtype/device 一致。编码器通常先归一化，但本损失直接使用输入值，不额外归一化。`log_z` 为固定有限 Python 标量；官方一次性估计 Z 的步骤不在范围内。均匀噪声可重复抽取，也可碰到正实例。损失仅对查询回传梯度。记忆更新 ID 必须互异，动量在 `[0,1]`，范数下界默认 `1e-12`；未选中行保持原样，零混合向量保持为零。

## 小实验与阈值

六个六维归一化实例向量执行 80 次 SGD，学习率 `.35`，T=`.2`，固定 Z=`exp(5)+5`，记忆动量 `.95`。每次枚举另外五个合成实例作为噪声候选，是确定性教学日程，并非复现原始随机采样。实验调用两个待实现函数；T3 要求损失低于 `.8` 且低于初值的 40%，查询与自身记忆平均余弦大于 `.99`，记忆保持单位长度且无梯度。没有图像编码器或下游指标复现。

数据和初始化均为确定性；测试 fixture 还将 Python、NumPy、PyTorch 的种子设为 42。原生标定环境为 Apple silicon 上仓库固定的 PyTorch 2.14.1 CPU。NumPy 自动微分适配器与导出的 WASM 包运行同一套完整训练测试。断言证明本合成任务上的数值和学习行为，不代表论文基准复现。

## 错误实现检查

以下每个 mutant 仅隔离一种错误，完整说明对应题面约定：

- 以 InfoNCE softmax 替代原始 binary NCE。
- 把 K/N 噪声先验错写成 1/N。
- 让历史记忆条目接收自动微分梯度。
- 对 K 个噪声项求平均而非求和。
- 交换 EMA 的新旧权重。
- 存储未归一化的 EMA 条目。
- 忽略固定的配分常数 Z。

来源：[论文](https://arxiv.org/abs/1805.01978) 与 [官方代码](https://github.com/zhirongw/lemniscate.pytorch/blob/master/lib/NCECriterion.py)。

原生参考解实测：initial_loss=2.34368; final_loss=0.661522; initial_alignment=0.574979; final_alignment=0.999562。

当非零 EMA 混合向量短于调用者给定的 epsilon 时，必须除以该 epsilon。固定使用 1e-12 会改变合法非默认输入的结果，专门的 mutant 与独立标量用例覆盖此边界。

momentum=1 的快捷路径不能返回输入别名：选中的非单位行仍需归一化，修改返回结果的任意行都不能影响原记忆库。
