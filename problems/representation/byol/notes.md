# BYOL 实现提示

1. 官方实现将两个方向相加后对 batch 求均值。本题没有额外的 `1/2`；不要直接照搬 SimSiam 题的尺度。
2. 官方 helper 用 `sqrt(max(sum(x*x),1e-12))`。把 `1e-12` 当作范数下界会改变近零向量。
3. 预测与另一视图目标配对；只有预测接收回归梯度。
4. EMA 的大权重在旧目标上。目标变化来自参数更新，不来自 loss.backward。
5. `m=0/1` 仍返回 detached 独立存储，避免后续修改结果污染输入。
6. 不归一化 EMA 参数，不把预测头参数与不对应的目标参数混合。

原生参考标定：80 次 SGD/EMA，45 个在线参数；初始 loss 2.035516，最终 0.002384，目标累计移动约 7.568853。损失/EMA 标量误差约 2.22e-16。macOS arm64、Python 3.14.2、PyTorch 2.14.1、CPU float64。8 个错误实现覆盖方向尺度、目标梯度、配对、epsilon、特征归约、EMA 权重、EMA 梯度和归一化。

梯度测试同时覆盖交错切片形成的非连续父张量，并要求未使用坐标的梯度为零。
