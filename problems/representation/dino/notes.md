# DINO 实现提示

1. 教师概率使用 `(raw_teacher − center) / teacher_temperature`。在 softmax 后减中心，或先除温度再减未缩放的中心，都是不同表达式。
2. 教师和中心都要 detach；学生 log 概率保留梯度。锐化后的教师概率仍需归一化。
3. 学生前两个视图与教师全局视图对应，只排除 `t=v`。每个额外学生裁剪都需匹配两个教师，总共 `2*(V−1)` 对。
4. 视图对与样本取平均，类别求和。同视图排除会改变每个学生的解析混合目标。
5. 中心来自原始教师 logits，两个视图和 batch 一同求均值。momentum 的大系数属于旧中心。
6. 当前损失使用旧中心，然后安装停止梯度的新中心。中心 EMA 不替代完整 DINO 中教师网络的参数 EMA。

原生参考校准：80 步 SGD/中心更新，54 个参数，交叉熵 1.107223 → 0.024133，合成类别一致率 1.0。标量误差低于 3e-16，教师始终无梯度。环境：macOS arm64、Python 3.14.2、PyTorch 2.14.1、CPU float64。11 个 mutant 覆盖中心化、教师锐化、教师梯度、视图排除、配对归约、学生温度、中心视图轴、动量权重和中心梯度。

梯度测试同时覆盖交错切片形成的非连续父张量，并要求未使用坐标的梯度为零。 多视图标量与解析梯度用例包含五个学生视图，检查额外局部裁剪及 2*(V−1) 的归约。
