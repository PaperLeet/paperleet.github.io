# MAE 实现坑点

本题只处理已划分 patch 的像素重建准则。MAE 的不对称编码器、轻量解码器、随机遮挡/恢复索引与预训练表示质量不在范围内。官方 `models_mae.py` 以 `torch.var` 默认样本修正归一化每个目标 patch，因此分母是 `P-1`。总体方差也是一种合法归一化选择，但不符合本题对齐的发布代码约定。这里的“像素坐标”包含展平后的所有通道。

归一化函数自身可微；损失在 detach 后的目标上调用它。官方图像数据通常本来就不求梯度，所以这一显式接口边界不改变通常训练行为。空 mask 返回零是本题扩展：分母至少为一，保留预测计算图，但不引入任何未观察 patch 的贡献。

| 错误 | 对应检验 |
| --- | --- |
| 总体方差 | `[-1,1]` 两坐标例区分分母 1 与 2。 |
| 沿 patch 轴归一化 | 独立标量值与各 patch 独立平移性质可定位错误轴。 |
| mask 反向 | 可见区域修改不得影响损失，预测梯度只在遮挡位置非零。 |
| 对全部 patch 求均值 | 不等遮挡数量例精确指定三个 patch 的全局均值。 |
| 像素误差求和 | 两像素 patch 必须对坐标误差取平均。 |
| 目标梯度泄漏 | 损失内目标无梯度，真实训练时目标不得漂移。 |
| 忽略归一化选项 | 原始与归一化模式各有独立标量 oracle。 |
| 停止预测梯度 | 标量损失必须保持对预测的计算图连接。 |
| 非连续输入梯度丢失 | 交错父存储 VJP 覆盖原始/归一化重建及独立归一化函数，未使用存储梯度必须精确为零。 |

独立归一化 VJP 使用 Python 标量算术的有限差分校验，不调用参考函数。T3 在 24 个确定性 context 上训练 16 个共享解码器参数，监督其中 14 个 patch，以 `.06` 学习率更新 120 次。原生 PyTorch 2.14.1、CPU float64 实测 MSE 由 `.67053234` 降至约 `6.57e-6`，通过 `1e-4` 和相对 `.001` 阈值。公共 fixture 固定 seed 42 并限制两条线程；实验本身无随机采样。将 target 加入 optimizer 是为了捕获移动标签的错误捷径。这是训练集合成重建，不是留出图像质量评测。
