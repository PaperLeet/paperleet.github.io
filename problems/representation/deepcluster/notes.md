# 实现提示

建议先独立完成练习，再查看本页。

按行计算带下界的范数，广播计算特征到各中心的平方距离，再沿中心维取 `argmin`。离散簇标签必须与梯度图分离；训练路径的归一化和全部分类 logits 保留梯度。用稳定的 log-sum-exp 计算样本平均交叉熵。

浮点矩阵为非空、有限的 float32/float64，同宽、同 dtype/device。标签为范围内 int64。默认 `eps=1e-12`，零向量归一化后仍为零；支持非连续输入，不修改输入。分配函数接收调用方已归一化的特征，不归一化中心。损失只对给定样本求均值；原系统通过采样平衡簇，本函数不会自动插入类别权重。starter 已提供输入验证。

## 小实验与阈值

九个确定性二维点形成三个簇，2×2 编码器和 2×3 分类头共十个可训练参数。以学习率 `.25` 做 90 次 SGD，在第 0、30、60、90 步更新伪标签和簇均值；空簇保留旧中心。实验实际调用三个待实现函数。T3 要求三个簇均被占用、编码器移动量大于 `.01`、伪标签准确率为 1、最终损失低于 `.1`。这些指标只描述合成训练，不包含 PCA 拟合或图像编码器复现。

数据和初始化均为确定性；测试 fixture 还将 Python、NumPy、PyTorch 的种子设为 42。原生标定环境为 Apple silicon 上仓库固定的 PyTorch 2.14.1 CPU。NumPy 自动微分适配器与导出的 WASM 包运行同一套完整训练测试。断言证明本合成任务上的数值和学习行为，不代表论文基准复现。

## 错误实现检查

以下每个 mutant 仅隔离一种错误，完整说明对应题面约定：

- 沿批次而非每行特征进行归一化。
- 选择最远簇而非最近簇。
- 用未归一化的点积替代欧氏距离分配。
- 对样本损失求和而非求均值。
- 把所有簇标签当成第 0 类。
- 切断特征归一化的梯度。

来源：[论文](https://arxiv.org/abs/1807.05520) 与 [官方代码](https://github.com/facebookresearch/deepcluster/blob/main/clustering.py)。

原生参考解实测：initial_loss=1.09861; final_loss=0.0695958; initial_accuracy=0.333333; final_accuracy=1。

非零行的范数小于 eps 时属于 z=x/eps 的线性分支，非连续父张量上对应 VJP 为 g/eps，未使用存储梯度为零。只单独处理全零行会漏掉此边界。
