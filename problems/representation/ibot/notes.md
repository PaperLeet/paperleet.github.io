# iBOT 实现坑点

本题对齐官方 `iBOTLoss.forward` 中同视图的 patch 项。完整目标还有跨视图图像级 CLS 自蒸馏与相应 crop 项的平均；训练系统还以移动平均更新教师权重及 center。这些状态更新没有隐藏在本题损失内。固定 `[K]` center 只是官方 patch center 广播形状的简化。

教师中心化在温度 softmax 之前减去各 prototype 的偏置。要 detach 最终概率分布，不能只 detach logits 后再减一个可微 center；梯度边界同时覆盖两者。学生温度还产生 `1/student_temp` 的链式导数。软目标保留不确定性：学生匹配教师后，CE 等于熵，KL 等于零。

| 错误 | 独立检验证据 |
| --- | --- |
| 缺少 center | 非常量 prototype 偏置改变独立计算的目标概率。 |
| 忽略教师温度 | 测试同时覆盖较尖锐默认温度与较软显式温度。 |
| 教师或 center 梯度泄漏 | 目标须停止梯度、损失无对应导数，训练中两者不移动。 |
| 忽略学生温度 | 学生解析梯度显式包含其链式缩放。 |
| 全局遮挡均值 | `1,2,0` 个遮挡 patch 的图像区分官方图像均衡归约。 |
| 纳入可见 patch | 改变其分数不影响损失，可见学生参数不能移动。 |
| 图像对应错误 | 不对称教师示例揭示跨图像目标错配。 |
| 教师硬标签化 | 软概率、熵下界以及匹配分布时的零梯度排除 argmax。 |
| 非连续学生梯度丢失 | 交错父存储 VJP 保留每个 prototype 的导数，同时教师/center 父张量停梯度、未使用存储为零。 |

空 mask 行贡献零，但仍计入 batch 分母，与官方图内 clamp 公式一致。单 prototype 与极端分数测试分别覆盖边界和数值稳定性。中心差分使用独立标量 softmax/CE，只扰动学生，因为教师目标按定义停止梯度。

T3 使用 48 个学生 logits、`1,3,0` 个遮挡位置、`.08` 学习率的 120 次 Adam 更新及 `.7/.5` 温度。PyTorch 2.14.1 CPU float64 实测 KL `.10580984 → 1.80e-7`，CE `.81916371`，教师熵 `.81916353`。验收要求 KL 小于 `1e-5` 且小于初值的 `.001`，并检查教师、center、可见学生漂移均为零。公共 fixture 固定 seed 42 与两条线程；实验初值为确定性正弦函数。固定教师 logit 拟合只演示这个目标，不代表有用表示的涌现或在线 tokenizer 训练。
