# InfoNCE 实现提示

1. `positive_indices` 是列编号，不是类别语义标签，也不保证每行都等于零。
2. 对每行全部 K 个候选计算 logsumexp；正例也在分母内。排除正例会破坏概率归一化，甚至产生负损失。
3. 分母沿 `dim=1`，最终沿 batch 取 mean。重复一遍整个 batch 不应改变损失。
4. 原始 logits 很大时 `exp().sum().log()` 会溢出；稳定 logsumexp 可先减去每行最大值。
5. 不要 detach 分母：它对负样本的梯度是正的，对正样本也有贡献。完整梯度是 `(softmax-one_hot)/B`。
6. 分数是输入契约，不额外添加温度或归一化。SimCLR 的候选构造和归一化放在后续练习。
7. `K=1` 时唯一候选概率为 1，损失和所有梯度为零。

实验标定：确定性三角函数初始化；共享测试种子 42；float64 `6×4` 分数表；80 步全 batch SGD，学习率 1.5。初始预测作为基线，T3 要求最终正确率 1、平均正例概率 >0.9、loss <0.1 且低于初始的 10%、最小正负分差 >3。数值与独立标量 oracle 的最大误差 <1e-12。图表记录实际更新，不能用预设曲线替代。

原生测量环境：macOS 26.5.2 arm64、Python 3.14.2、PyTorch 2.14.1 CPU。参考结果：loss 1.527860 → 0.041209，正确率 1/3 → 1，平均正例概率 0.959630，最小分差 3.911801，独立数值误差 4.44e-16。
