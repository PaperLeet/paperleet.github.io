# 坑点与验证记录

## 归一化与矩阵方向

本题遵循官方 `main.py` 中 `BatchNorm1d(affine=False)` 的训练态数值约定：先沿 batch 中心化，方差除以 `B`，`eps` 加在平方根内。不是默认无偏样本方差，也不是沿特征轴的 LayerNorm。`C[i,j]` 关联第一视图第 i 个特征和第二视图第 j 个特征；输入视图不同时，`C` 一般不对称。

重复整组 batch 不应改变 `C`，这条性质能区分 `B` 与 `B-1`。独立的特征偏移被中心化消除；交换视图会转置 `C`，但完整损失不变。由于 `eps>0`，把输入乘常数并非严格不变量，除非同步把 `eps` 乘该常数平方。

## 损失尺度与梯度

对角惩罚与非对角惩罚都求和，不除以 `D` 或 `D(D-1)`。非对角项包括每一个有序对；只看上三角既会丢项，也会改变非对称矩阵的目标。`lambd=0` 不能删掉对角目标。

两组输入都参与反向传播，均值和方差也必须保持在计算图里。损失的双边有限差分与加权完整矩阵 VJP 各自使用独立标量 oracle。相同的前向矩阵不代表 detach 也是正确实现。

双视图精确塌缩时，矩阵为零，损失为 `D`，梯度仍为零。本实验从非恒定向量开始；不会声称任何初始化都能脱离塌缩。`D>B-1` 时中心化数据的秩也会限制达到完整单位矩阵。

## 对应错误实现

1. 不中心化：偏移不变性和独立 covariance 数值均失败。
2. 样本方差 `B-1`：违反官方 BN 约定和 batch 重复性质。
3. 沿行归一化：把特征标准化改成了样本标准化。
4. 矩阵除以 `D`：只有 `B=D` 时偶然掩盖错误。
5. 对角取均值：改变目标尺度。
6. 只取上三角：遗漏下三角的独立项。
7. detach 第二视图：前向相同，但双边梯度测试失败。
8. 在根号外加 epsilon：特别在近零方差与非默认 epsilon 时偏离契约。
9. 忽略 lambda：改变非对角惩罚权重。

每个 mutant 为独立完整文件，首行只说明该错误。它们保留输入检查与题目主体，单文件相对参考实现的增删行数不超过 10。

## CPU 实验标定

合成数据是 16 个均匀角度的 `cos(t), sin(t), cos(2t)` 基底，通过两组固定混合矩阵产生 `16×3` 视图；直接优化 96 个元素，无数据下载。初始化不使用随机数（全套 fixture seed=42）。优化器为 Adam，学习率 `.04`，`lambd=.2`，`eps=1e-5`，更新 120 次。基线为同一初始向量表的真实目标。

在 macOS CPU / Python 3.14.2 / PyTorch 2.14.1 上，参考实现初始损失约 `1.00230136`，最终损失 `1.21073e-5`，对角误差 `1.16493e-5`，非对角平方和 `2.28994e-6`。独立标量矩阵与提交矩阵最大差约 `1.1e-16`。验收阈值固定为损失减少到 1% 以下、对角误差 `<.005`、非对角平方和 `<.01`，并核对独立 oracle。阈值衡量这次确定性的教学优化，不代表论文预训练性能。
