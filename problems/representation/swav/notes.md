# SwAV 实现提示

1. 内部传输矩阵为 K×B。先把原型行归一化为 1/K，再把样本列归一化为 1/B；返回前乘 B 并转置。
2. 有限迭代轮数属于题目契约。最后的列步骤保证样本概率行和为一；原型平衡需随迭代收敛，不能假设始终精确成立。
3. 在对数域归一化避免溢出。所有得分同时平移一个常数不改变分配；任意逐原型偏置在有限轮后不一定消失。
4. 分配 epsilon 与预测温度独立，即使默认值接近也不可混用。
5. 两个 API 都要阻断分配梯度。损失交叉配对视图，并平均两个方向。
6. 软目标交叉熵通常不能趋近零；减去目标熵后才得到衡量预测差异的 KL 项。

原生参考校准：80 步 Adam，36 个参数，交叉熵 1.218270 → 1.035732，目标熵下界 1.035710，最终差值 2.15e-5。分配和标量误差低于 7e-16。环境：macOS arm64、Python 3.14.2、PyTorch 2.14.1、CPU float64。9 个 mutant 覆盖原型平衡、batch 缩放、分配 epsilon、分配梯度、视图配对、损失目标梯度、方向归约和预测温度。

梯度测试同时覆盖交错切片形成的非连续父张量，并要求未使用坐标的梯度为零。
