# BEiT 实现坑点

官方训练代码在不求梯度时获取视觉 token ID，选择 Boolean mask 指定的位置，再把所选 logits 与 ID 交给普通均值交叉熵。这里的目标是离散硬标签。图像 tokenizer、其训练数据、遮挡图像 Transformer，以及由 token code 重建图像均不在本题范围内。

必须先筛选位置再 gather 标签。可见 sentinel 不代表词表准则内的 `ignore_index`，更不能意外索引到某个类别。空 mask 的零损失属于教学扩展；通常的 BEiT 训练会提供遮挡 token。零值与 `logits.sum()` 相连即可保留全零梯度。

| 错误 | 独立检验证据 |
| --- | --- |
| 监督全部或仅可见 token | 改变可见分数不影响目标，非零梯度只能位于遮挡位置。 |
| 除以 batch 大小 | 不等遮挡数量例有精确的 token 均值标量答案。 |
| 概率当 logits | 标量 log-sum-exp 与 `(p-one_hot)/M` 梯度揭示额外 softmax。 |
| 标签类别错位 | 非均匀分数和不同 ID 锁定每个目标坐标。 |
| detach logits | 损失必须有计算图，遮挡位置导数满足解析公式。 |
| 符号反向 | 均匀分数应得到正的 `log(K)`，真实训练须降低 CE。 |
| 非连续 logits 梯度丢失 | 交错父存储 VJP 保留各选中类别导数，未使用存储梯度为零。 |
| 提前 gather 可见 sentinel | 正负混合越界可见 ID 都必须在 gather 前被忽略。 |

T3 从 12 个确定性 one-hot context 学习 16 个共享分类头参数；六个遮挡位置覆盖四个类别。Adam 以 `.08` 更新 100 次。PyTorch 2.14.1 CPU float64 的 CE 实测为 `1.38629436 → .01292025`，准确率 `1.0`；验收要求 CE 小于 `.03` 且小于初值的 `.03`，并正确分类所有训练标签。公共种子为 42，原生线程上限为二；本实验无随机采样。context 刻意易于分类，以展示提交函数的真实优化，不衡量泛化或 tokenizer 质量。独立数值梯度测试进一步限制仅在训练示例上有效的捷径。
