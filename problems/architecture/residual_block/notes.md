# 理解残差块

当两处 ReLU 都激活时，按行向量约定，恒等捷径的 Jacobian 为 `I + W1 @ W2`，投影捷径则为 `Ws + W1 @ W2`。存在非激活单元时，需要插入对应的对角激活掩码；最后的 ReLU 意味着恒等捷径并不保证所有位置的梯度都非零。

标量 oracle 独立计算两层映射；梯度检查覆盖输入、两层权重与投影，因此前向数值正确不能掩盖 detach 错误。

六个 mutant 分别漏掉捷径、漏掉最终激活、在相加前额外激活残差、detach 捷径、detach 残差，以及忽略显式投影。Pre-activation 网络可以是合法架构，但不符合本题原始 post-activation 的约定。

训练图显示的是你实现的四块模型的真实损失，没有把完整训练的 plain network 与卷积 ResNet 作比较。末层零初始化让正输入上的起点便于检查，这是教学选择，不声称复现论文的初始化配方。
