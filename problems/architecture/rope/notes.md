# 通过后的复盘

位置乘频率，不是特征乘频率。第 i 对使用 `base**(-2*i/D)`；索引、分母或配对布局改变，都会改变函数。

正角度必须按题面逆时针旋转。反向旋转仍保范数、满足组合与共同平移性质，所以测试还必须有带方向的手算例子和独立标量公式。

缓存中的位置属于原序列。追加块的第一个 token 不一定在位置零；q/k 长度不同也无需强行共享位置向量。不要把 value 也旋转。

浮点 positions 与 x 都应保留计算图，不能为了转换精度而先转 Python 列表或 detach。输入 VJP 等于上游梯度的逆旋转；位置 VJP 要累加所有 batch、head、特征对的贡献。float64 输入若先用 float32 相位，最后转回 float64 也无法恢复精度。

相邻配对和前后半区配对对应不同的特征布局，不能不改投影权重就混用。实验里“共同位移后相同”是数学恒等式；合成曲线和缓存偏移演示都不代表真实模型的长上下文质量。
