# GQA 常见坑点

1. **连续共享与循环平铺不同。** H=8、G=2 时，每个 KV 头服务连续四个 query 头。直接 `repeat` 往往给出交错的头顺序；检查 `[0,0,0,0,1,1,1,1]` 的映射。
2. **缩放的是特征维度。** logits 除以 $\sqrt D$，而不是头数、组数或组宽。
3. **均值转换不等价于原 MHA。** 投影先平均、再经过 softmax，与分别做注意力后平均一般不同。G=H 保持原模型，但其他 G 的转换可能改变输出；合成误差不是准确率。
4. **共享头接收梯度的和。** 设 $\mathcal H_g$ 为 KV 头 g 服务的 query 头集合，则 $\partial L/\partial K_g=\sum_{h\in\mathcal H_g}\partial L_h/\partial K_g$；V 同理。不要在展开前 detach，也不要人为再除以组宽。
5. **投影转换的梯度才有平均因子。** 若组宽为 r，每个原投影头得到池化输出梯度的 1/r。与共享注意力中的求和区分开。
6. **空 mask 行需要显式约定。** 先避免对全负无穷求 softmax，再把不可见权重置零。错误的广播或忽略 mask 会泄漏未来信息。Q≠K 时应由调用方传入所需可见性。
7. **缓存小不代表本题实现一定更快。** 教学实现可展开 KV 来计算；实验只统计持久 KV 数量，没有测 GPU 内核、带宽或吞吐。

原论文：[GQA，§2.1–2.2](https://aclanthology.org/2023.emnlp-main.298.pdf)。均值池化是检查点转换步骤；完整上训练不在本题范围内。
