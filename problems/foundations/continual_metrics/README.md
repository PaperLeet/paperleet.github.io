# 96. 持续学习：评估矩阵与遗忘指标

## 1. 问题

顺序学习新任务时，只看当前任务的准确率无法判断旧能力是否保留。GEM 的评估协议在每个训练阶段后评估各任务，用一个矩阵描述学习、遗忘和迁移。阅读 [原论文 §2、Eq. (2)–(4)](https://papers.nips.cc/paper/2017/file/f87522788a2be2d171666752f97ddebb-Paper.pdf)。

实现一个评估函数。矩阵和训练前基线已经给定；不需要训练 GEM、实现梯度投影或先完成其他题。提供的实验会真正顺序训练一个小分类器，并调用你的函数计算每阶段指标。

```python
continual_metrics(scores: Tensor, baseline: Tensor) -> dict[str, Tensor]
```

## 2. 核心公式

使用从 **0** 开始的索引。共有 `T>=1` 个任务，按 `0,1,...,T-1` 顺序训练。

- `scores[i,j] = R[i,j]`：**学完任务 i 后**，在**任务 j 的测试集**上的准确率。行是训练阶段，列是被评估任务，shape `[T,T]`。
- `baseline[j] = b[j]`：开始训练任何任务之前，在任务 j 上的准确率，shape `[T]`。它不是每个阶段重算的基线。

对于 `T>1`：

\[
\mathrm{ACC}=\frac1T\sum_{j=0}^{T-1}R_{T-1,j},\qquad
\mathrm{BWT}=\frac1{T-1}\sum_{j=0}^{T-2}(R_{T-1,j}-R_{j,j}),
\]
\[
\mathrm{FWT}=\frac1{T-1}\sum_{j=1}^{T-1}(R_{j-1,j}-b_j).
\]

这三个指标来自 GEM。正 BWT 表示后续训练改善了旧任务；正 FWT 表示尚未训练任务 j 时，前面任务的学习已使它超过初始化基线。

本题另外定义**非负历史峰值遗忘**，用于与 BWT 对照；它不是 GEM Eq. (2)–(4) 中的指标：

\[
\mathrm{forgetting}=\frac1{T-1}\sum_{j=0}^{T-2}
\left(\max_{j\le i\le T-1}R_{i,j}-R_{T-1,j}\right).
\]

峰值只考虑任务 j 学完之后，**包含最终阶段**，因此不会为负。最后一个任务没有后续训练，不参与 BWT 或 forgetting。

返回恰好包含 `acc`、`bwt`、`fwt`、`forgetting` 四个键的字典，每个值都是 shape `()` 的 Tensor。`T=1` 时，`acc=R[0,0]`，其余三个指标为 0。

## 3. 从公式到代码

先区分要访问的区域：最终行用于 ACC；旧任务对角与最终行用于 BWT；第一条上对角线用于 FWT；各旧任务从对角向下的历史用于峰值遗忘。先算每个任务的差值，再按公式等权平均。

例如：

```text
R = [[0.5, 0.2, NaN],
     [0.9, 0.6, 0.3],
     [0.7, 0.8, 0.9]]
b = [NaN, 0.1, 0.15]
```

结果是 `acc=0.8, bwt=0.2, fwt=0.125, forgetting=0.1`。任务 0 最终从刚学完时的 0.5 提升到 0.7，但也从中间峰值 0.9 回落了 0.2；所以 BWT 为正时仍可能有峰值遗忘。

## 4. 本题约定

| 项目 | 约定 |
| --- | --- |
| 输入 | CPU float32/float64；两个输入 dtype/device 一致；`T>=1` |
| 有效分数 | 用到的准确率与基线为有限数，位于 `[0,1]` |
| 无用区域 | `R[i,j]` 中 `j>i+1` 的位置及 `b[0]` 不使用，可为 NaN |
| 未来任务 | FWT 需要 `R[j-1,j]`；其他更早的未来任务评估不能参与指标 |
| 归一化 | 任务等权；不是按测试样本数加权，也不是平均整个矩阵 |
| 输出 | 四个标量 Tensor，保持输入 dtype/device |
| 副作用 | 不修改输入，不保留跨调用状态；没有梯度要求 |

测试只提供符合以上形状与取值契约的输入，不要求编写通用输入校验。峰值遗忘若只比较“最终阶段之前”的峰值且允许负数，会得到另一种合法定义，但不符合本题已明确的非负约定。

真实项目中，训练、验证和测试应分开。可在固定测试集上报告各阶段表现，但不能据此选择超参数；多轮对话的不同轮次或同源样本也不应跨训练与测试集泄漏。这些是评估设计提醒，不是本函数需要推断的数据属性。

## 5. 交互图与真实实验

[查看顺序学习评估](#viz-sequential_evaluation)。图展示一个只有两个权重的 logistic 分类器，依次学习三个合成二分类任务。三个任务使用不同方向定义标签，故存在能力冲突。每任务使用 64 个训练输入和另外 80 个测试输入，零初始化，学习率 0.8，每任务 36 步全 batch SGD；圆周网格确定生成，无随机采样。

训练更新只读取训练数据。每阶段在独立测试网格上计算预测准确率、填入 R，再调用你的 `continual_metrics`；图上的指标由该调用产生。训练前模型是基线，独立标量公式检查指标。T3 要求当前任务准确率至少 0.9，并要求这条刻意冲突的任务流产生大于 0.25 的最终峰值遗忘。阈值仅适用于该微型实验。

这展示了评估协议，不实现 GEM 优化器、replay、LLM 持续训练或论文基准。通过本题不意味着模型已经解决遗忘。

## 7. 延伸

解释为什么最终平均准确率相近的模型，可能具有不同的 BWT 和 FWT；为什么历史峰值遗忘不能直接写成负 BWT。进一步阅读 GEM §3 的记忆梯度约束，再比较 EWC 参数约束与 replay 数据回放的作用。它们是可研究的方法，并不预设你自己的项目采用了任何一种。
