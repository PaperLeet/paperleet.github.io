# 坑点与诊断

- **把行列看反。** 最终能力来自最后一行；对角线只记录每个任务刚学完的时刻。平均对角线不是最终 ACC（mutant m1）。
- **BWT 符号反了。** 最终减去刚学完，正值表示改善；不能把它统一当作“损失量”（m2）。
- **FWT 读取已训练的分数。** 用 `R[j-1,j]`，不能用 `R[j,j]`，也不能对未来任务的整个上三角求平均（m3）。
- **把 forgetting 写成 -BWT。** 两者基准分别是历史峰值和对角线；任务先升后降时可能两者都为正。这里峰值包含最终阶段，故 forgetting 非负（m4）。
- **偷读无用区域。** `j>i+1` 的矩阵元素和 baseline[0] 可为 NaN。任务 j 的峰值从阶段 j 开始，不含它尚未学过时的高分。
- **混淆平均分母。** ACC 有 T 个任务，其他指标有 T-1 个相关任务；T=1 时后三项直接为 0，不能除以零。
- **误解论文范围。** ACC/BWT/FWT 来自 GEM；本题非负峰值遗忘是明确标注的扩展。实验只演示真实训练后的评估，不实现 GEM 梯度投影。

参考解对峰值历史做简单循环，时间 O(T²)，除输出外额外临时存储 O(T)。也可以用向量化实现，只要不让无用单元影响结果。题目不要求 autograd，也不应把阶段测试指标用于挑选训练超参数。
