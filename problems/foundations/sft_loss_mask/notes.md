# 实现要点

logits 去尾，标签和两个掩码去头。先求有效 token 的损失总和，再除以有效数量，不能先按序列平均。全屏蔽时仍需保留零梯度计算图。

典型错误：

- 错位时使用预测位置的回答掩码。
- 忽略 attention_mask。
- 除以所有位置数，而非有效 token 数。
- 切断回答损失梯度。

## 掩码与归约

设回答掩码 r、有效位置掩码 a，则预测位置 t 的损失权重来自目标位置 t+1 的 `r & a`。回答的第一个 token 通常由 prompt 的最后一个位置预测，因此不能把预测位置属于 prompt 当成排除理由。

例如两条样本分别有 1 个和 3 个有效回答 token，应对 4 个 token 平均。先计算两条样本的平均损失，再等权平均，会改变学习目标。全屏蔽样本不贡献分子和分母。

本题的 mask 已由调用者提供；聊天模板解析、跨文档 packing 边界由上游处理。时间 O(BTV)。

先对 logits 减去每行最大值，再计算 logsumexp 与正确类别之差。否则 1e20 等共同偏移会吞掉 log(V)，连均匀分布的损失与梯度也会算错。参考解使用 float64 中间量，最终恢复输入 dtype。
