# 实现要点

先汇总所有平方和，再开根号，只计算一个缩放系数。返回原始范数，不是裁剪后的范数；小梯度不能被放大。

典型错误：

- 分别按每个参数范数裁剪。
- 使用逐元素截断。
- 未限制缩放比例上限，放大小梯度。
- 返回裁剪后范数。

## 全局缩放保留方向

两个参数梯度分别为 `[3]` 和 `[4]`，全局范数是 5。最大范数为 2.5 时，两者都乘以 `2.5/(5+eps)`。若分别裁剪，各自的缩放不同，会改变联合梯度方向。

逐元素 clamp 同样不等于范数裁剪。上限不生效时 scale 应为 1；返回的 total_norm 用于记录裁剪前梯度，不能用裁剪后的数值替代。

在训练流程中，先完成梯度累积；若用了 loss scaling，先 unscale，再进行一次全局裁剪，最后更新参数。本题输入已是待更新梯度，不涉及混合精度状态。P 为所有参数元素总数，时间与输出空间均为 O(P)。

极大或极小的有限梯度应先除以全局最大绝对值，再以 float64 平方归约，最后恢复尺度，避免范数仍可表示时中间平方先溢出或下溢。分母也须按尺度改写，让极小梯度中的 epsilon 保持有效。
