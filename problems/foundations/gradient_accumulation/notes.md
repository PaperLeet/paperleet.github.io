# 实现要点

每个输入已经除过自己的 token 数，先乘回计数再求全局平均。零 token 批次不应稀释分母。实验用不等长小批次验证同一次参数更新与完整批次相同。

典型错误：

- 等权平均不同 token 数的 microbatch。
- 加权求和后未除全局 token 数。
- 又除以累积步数。
- 只返回最后一个 microbatch 梯度。

## 为什么不能直接平均

例如两个 microbatch 的平均梯度是 1 和 5，有效 token 数为 1 和 3：正确结果是 `(1×1+3×5)/4=4`，直接平均得到 3。

这相当于对所有 token 的损失总和求梯度，再除以总 token 数。已在局部 loss 中求平均后，累积时应恢复对应权重；不要再次按累积步数缩小梯度。优化器只在累积完成后执行一次更新。

本题处理同一个参数的多个 microbatch 梯度；多参数模型可对每个参数独立使用相同权重。P 为该参数元素数，M 为 microbatch 数，时间 O(MP)，额外累积空间 O(P)。
