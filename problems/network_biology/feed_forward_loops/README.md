# 网络模体：在有向调控网络中检测前馈环

节点列表和非法输入沿用“生物互作网络：节点度与度分布”（第 93 题）的约定，但这次的图是**有向**的。你要在基因调控网络中寻找一种反复出现的小模式：前馈环。

## 任务与标准约定

边 `(u, v)` 表示“`u` 调控 `v`”，与 `(v, u)` **不同**。节点是互不重复的 `str` 名称。重复的边只算一条，自环（自调控）被忽略，节点名重复或边端点未知抛出 `ValueError`。

```python
find_feed_forward_loops(nodes, edges, induced=False) -> list[tuple[str, str, str]]
```

**前馈环（FFL）**是由三个*互不相同*的节点组成的有序三元组 $(x,y,z)$，满足

$$
x\to y,\qquad y\to z,\qquad x\to z.
$$

其中 `x` 是顶层调控因子，`y` 是中间节点，`z` 是靶标：`x` 既直接作用于 `z`，又通过 `y` 作用于 `z`。

- `induced=False`：三个节点之间允许存在其他边。
- `induced=True`：这三条边必须是三个节点之间**仅有**的边，即不存在 $y\to x$、$z\to x$、$z\to y$。

返回所有这样的三元组，按升序排列，元素是字符串组成的元组。角色由边的方向决定，而不是名称。`induced=False` 时，如果三个节点之间还有反向边（例如除了三条 FFL 边之外还有 `z -> y`），同一组三个节点可以给出两个三元组。

## 示例

```python
nodes = ["TF1", "TF2", "G1"]
edges = [("TF1", "TF2"), ("TF2", "G1"), ("TF1", "G1")]
find_feed_forward_loops(nodes, edges)                      # [('TF1', 'TF2', 'G1')]
find_feed_forward_loops(nodes, edges + [("G1", "TF2")])    # [('TF1', 'G1', 'TF2'), ('TF1', 'TF2', 'G1')]
find_feed_forward_loops(nodes, edges + [("G1", "TF2")], induced=True)  # []
```

链 `x->y->z`、扇出 `x->y, x->z`、扇入 `x->z, y->z` 以及有向环 `x->y->z->x` **都不是**前馈环。环与前馈环的*无向*骨架相同，都是三角形：三角形共有八种定向方式，其中六种含一个前馈环，两种（环）不含。方向才是关键。

## 动手前想一想

为每个节点保存它所调控的节点集合。对每个 `x` 及其每个靶标 `y`，`z` 的候选是同时被 `y` 和 `x` 调控的节点。按排序顺序循环，输出就是有序的。`induced=True` 时，还要排除含有三条反向边之一的三元组。

## 模体能说明什么、不能说明什么

在所引用的工作中，*网络模体*是在真实网络中出现次数显著高于同度分布随机网络的互连模式。本题只负责**找出**模式；它是否过度出现是另一个统计问题（配套实验只把一个计数与保持度的随机化结果作比较，并不声称显著性）。即使 FFL 过度出现，也只是结构上的观察：它并不说明调控是激活还是抑制，环是否有功能，或它是否被选择保留。这些结论需要符号信息、动力学和实验。这里的网络都是合成的。
