# 实现笔记

先建好邻居集合并重复使用。一种易读的介数实现是：从每个节点出发做广度优先搜索（BFS），同时记录到其他每个节点的距离和最短路径条数 $\sigma$；当某个邻居恰好比当前节点远一层时，把当前节点的条数累加给它，即可得到 $\sigma$。然后遍历无序点对 $\{s,t\}$，当 `dist(s,v) + dist(v,t) = dist(s,t)` 时，给节点 `v` 加上 $\sigma_{sv}\sigma_{vt}/\sigma_{st}$。

常见错误：

- 度中心性除以 `N` 而不是 `N - 1`。
- 统计有序点对，导致分数翻倍（归一化中缺少因子 2）。
- 把路径端点也计入。
- 只要 `v` 在*某条*最短路径上就加 `1`，而不是加上经过 `v` 的最短路径所占比例（有多条等长路径时就会出错，例如 4 节点环）。
- 忽略并列规则，或直接比较原始浮点数，使 `0.1 + 0.2` 与 `0.3` 被当作不同。
- 对不连通的点对令 `sigma = 0` 并除以零。

## 复杂度

上面的点对循环在 N 次 O(N + M) 的广度优先搜索之后是 O(N^3)。Brandes 算法对每次 BFS 反向累积依赖，无权图上的时间为 O(NM)；只要满足上述约定，也可以使用它。

## 为什么两种排名不同

度只看节点的直接邻域，所以排在前面的是 `A1` 和 `B1`；介数看全局路径，所以连接节点 `X` 即使度很低也排第一。添加捷径 `A4-B4` 给两个模块多了一条路线，`X` 的介数随之下降：图中一条边的改变就会移动一个全局分数。

## 科学上的谨慎

哪个分数“正确”取决于要回答的问题。两者都不度量必需性；枢纽是否必需、瓶颈是否适合作为干预靶点、连接节点在生理上是否重要，都必须用实验检验。玩具图上的中心性不能说明真实互作组。
