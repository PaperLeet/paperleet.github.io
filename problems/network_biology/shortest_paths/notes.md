# 实现笔记

从 `source` 出发做广度优先搜索，按排序后的顺序扩展每个节点的邻居，并在节点第一次被看到时记录 `distance` 和 `parent`。距离直接来自搜索；路径通过从目标沿父节点回溯到起点并反转列表得到。

为什么这样得到字典序最小的路径：BFS 逐层处理，并且（归纳可得）一层内节点按其最优路径的字典序排列；每个节点的父节点是这个顺序中第一个与它相邻的节点，因此把该节点接在父节点的最优路径后就得到它的最优路径。

常见错误：

- 对不可达目标返回 `0` 或抛异常，而不是 `None`。
- 报告路径上的节点数而不是边数。
- 遍历未排序的 `set`，使并列结果取决于哈希顺序。
- 忘记反转父节点链，或在 `source == target` 时返回空路径。
- 把边当作有向边，或不校验目标节点。

## 复杂度

一次 BFS 为 O(N + M)（外加邻居列表排序）。全点对距离需要 N 次搜索；测试中的穷举路径基准只能用于很小的图。

## 科学上的谨慎

短路径是关于已记录图的陈述，并不说明两个蛋白共同起作用：混杂的枢纽会在无关过程之间制造短路径，缺失的互作会造成长路径或没有路径。请把邻近性当作待检验的假设，而不是结论。
