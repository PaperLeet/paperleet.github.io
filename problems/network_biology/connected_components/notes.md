# 实现笔记

先建好邻居集合，按排序后的顺序遍历节点，用栈（深度优先）或队列（广度优先）扩展每个分量。节点在*入栈*时就标记为已访问，这样不会被重复入栈。每个分量排序后，再按 `(-大小, 第一个名称)` 对分量列表排序。

常见错误：

- 因为孤立节点不出现在任何边中而漏掉它们。
- 每条边只记录一个方向，使结果取决于先写了哪个端点。
- 并列时按错误的节点排序（最大名称或发现顺序）。
- 用分量个数而不是节点数去除最大分量的大小。
- 对很长的链使用递归而超出 Python 的递归深度限制；请用显式栈。

## 复杂度

建图并遍历所有节点合计 O(N + M)，再加上排序的 O(N log N)。

## 科学上的谨慎

分量是关于已记录图的陈述。最大分量的占比取决于已记录数据的完整性与偏倚。不连通的分量应读作“没有已记录的路径”，而不能当作两个蛋白互不影响的证据。
