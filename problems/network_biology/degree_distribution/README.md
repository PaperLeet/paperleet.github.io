# 生物互作网络：节点度与度分布

可独立完成的网络生物学练习，无需先做完其他题。只需要 Python 的字典、集合和循环。这是“网络生物学”合集的第一题。

## 任务与标准约定

把蛋白质互作（PPI）网络建模为**简单无向图**。`nodes` 是互不重复的 `str` 名称列表，`edges` 是 `(u, v)` 对的列表，每对内部的顺序无关。

- 重复出现的边，或写成相反顺序的同一条边，只算一条边。
- 自环 `(u, u)` 被忽略。这是建模约定：真实蛋白可以与自身相互作用，但简单图不含自环。
- 没有任何伙伴的节点仍出现在结果中，度为 `0`。
- `nodes` 中出现重复名称，或边的端点不在 `nodes` 中，抛出 `ValueError`。

```python
node_degrees(nodes: list[str], edges: list[tuple[str, str]]) -> dict[str, int]
degree_distribution(nodes: list[str], edges: list[tuple[str, str]]) -> dict[int, float]
```

节点的**度**是它不同邻居的个数，是单个蛋白的性质；**度分布**则是整个网络的性质：

$$
k_v=|N(v)|,\qquad P(k)=\frac{n_k}{N},\qquad n_k=|\{v: k_v=k\}|.
$$

`degree_distribution` 对每个整数 `k = 0, 1, ..., 最大度` 返回 `P(k)`，键按升序排列；没有节点取该度时记为 `0.0`。没有节点的图返回 `{}`。

## 示例

合成的玩具网络（不是实验数据）：节点 `P1`…`P8`，边 `P1-P2, P1-P3, P1-P4, P1-P5, P2-P3, P5-P6, P6-P7`。

```python
node_degrees(nodes, edges)
# {'P1': 4, 'P2': 2, 'P3': 2, 'P4': 1, 'P5': 2, 'P6': 2, 'P7': 1, 'P8': 0}
degree_distribution(nodes, edges)
# {0: 0.125, 1: 0.25, 2: 0.5, 3: 0.0, 4: 0.125}
```

## 动手前想一想

为每个节点建立邻居*集合*，重复边会自动合并；跳过 `u == v`；使用端点之前先校验。然后统计每个度对应多少节点，再除以节点总数。

## 图能说明什么、不能说明什么

一条边是某种实验或数据库记录的互作。记录取决于实验方法且并不完整，所以节点的度是“已记录的伙伴数”，并不衡量生物学重要性。这里的玩具图都是合成的。文献中关于长尾或“无标度”度分布的描述是需要用数据和统计检验的假设；本题不拟合幂律。
