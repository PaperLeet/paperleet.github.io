# 实现笔记

为每个节点使用一个邻居 `set`。对每条非自环边同时插入两个方向；集合会去掉重复边和反向重复边。读取边时校验端点，并先校验节点列表，再构建其他结构。

常见错误：

- 重复边或反向边被计两次（用邻居列表而不是集合）。
- 把自环当作普通边计入。
- 只报告出现过的度，导致缺失的度（这里是 `k=3`）悄悄从直方图里消失。
- 除以边数而不是节点数。
- 因为孤立节点不出现在任何边里就把它丢掉。

## 复杂度与设计

构建邻居集合需要 O(N + M) 的时间和空间（N 个节点、M 条给定的边）。直方图为 O(N + k_max)。`degree_distribution` 是 `node_degrees` 的函数，这正是本题要说明的：度分布会忘记*哪个*蛋白具有哪个度。

稠密直方图（键为 `0..最大度`）是为了让两个网络可以逐位置比较并无缺口地绘图而选定的约定。握手恒等式可用来快速自查：各节点的度之和等于不同非自环边数的两倍，所以平均度为 2M/N。

## 科学上的谨慎

度只统计已记录的互作。高度数的节点可能是文献中被研究得多、容易被该实验检出，也可能确实具有很多伙伴；仅凭图无法区分。不要把度当作重要性或必需性。
