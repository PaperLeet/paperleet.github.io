# 社区发现与候选生物学模块

沿用“生物互作网络：节点度与度分布”（第 93 题）的图约定。你要用**模块度**给网络的划分打分，并实现一个确定性的贪心算法来提出**社区**，社区可被解读为候选的功能模块。

## 任务与标准约定

简单无向图：`str` 节点名唯一，`(u, v)` 对内顺序任意，重复或反向重复的边只算一条，自环被忽略，节点名重复或边端点未知抛出 `ValueError`。设 `m` 为不同的非自环边数，$D_c$ 为社区 `c` 中节点度之和。

```python
modularity(nodes, edges, communities, resolution=1.0) -> float
greedy_modularity_communities(nodes, edges, resolution=1.0) -> list[list[str]]
```

$$
Q_\gamma=\sum_{c}\left[\frac{L_c}{m}-\gamma\left(\frac{D_c}{2m}\right)^2\right],
$$

其中 $L_c$ 是两端都在社区 $c$ 内的边数，$\gamma$ 即 `resolution`。`m = 0` 时 `modularity` 返回 `0.0`。`communities` 必须是一个划分：非空列表、互不相交、恰好覆盖每个节点一次，否则抛出 `ValueError`。

**贪心算法（确定性，不含随机性）。** 从每个节点各自成一个社区开始。把由 $e_{ab}\ge 1$ 条边相连的两个社区 `a` 和 `b` 合并，$Q_\gamma$ 的变化为

$$
\Delta Q=\frac{e_{ab}}{m}-\gamma\,\frac{D_aD_b}{2m^2}.
$$

反复执行 $\Delta Q$ 最大的合并，比较增益时**四舍五入到 12 位小数**。当最大增益不是严格为正时停止。若多对社区的舍入增益相同，则合并 `(a 的最小成员, b 的最小成员)` 名称对最小的那一对，其中取 `a` 的最小成员较小。彼此之间没有边的社区永不合并，所以孤立节点保持独立，没有边的图返回单点社区。

每个社区返回为排序后的名称列表，社区按大小（从大到小）再按最小成员排序。没有节点时返回 `[]`。

## 示例

合成网络（不是实验数据）：三角形 `A1,A2,A3` 与 `B1,B2,B3` 由边 `A3-B1` 相连。

```python
greedy_modularity_communities(nodes, edges)
# [['A1', 'A2', 'A3'], ['B1', 'B2', 'B3']]
modularity(nodes, edges, [["A1","A2","A3"], ["B1","B2","B3"]])   # 5/14 = 0.357142...
modularity(nodes, edges, [nodes])                                # 0.0
```

对由一条边相连的两个 4 节点团，`resolution=0.1` 得到一个社区，`1.0` 得到两个团，`4.0` 得到八个单点。得到的划分依赖于参数。

## 动手前想一想

为每个社区保存成员列表、度之和，以及“邻居社区 → 之间的边数”的映射。每一轮扫描每个相连的社区对一次，按 `(−舍入后增益, a, b)` 选出最优对，把 `b` 并入 `a` 并更新邻居映射。用最小成员标识社区，并列规则就容易应用。

## 社区能说明什么、不能说明什么

检测到的社区是内部连接比模块度零模型预期更密的一组节点；它是**候选**的结构模块。不同算法、参数（这里是 `resolution`）、并列规则，甚至图的微小改动，都可能给出不同的划分；模块度最大化对小模块还有已知的分辨率极限。检测到的模块不是经实验验证的通路、复合物或功能单元：要把它们与生物学联系起来，需要注释富集、重复验证和实验。所引用的论文研究的是代谢网络的模块化组织；这里的算法是通用教学方法，并非该论文的流程。所有图都是合成的。
