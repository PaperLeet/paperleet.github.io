# 实现说明

先中心化奖励，计算总体均方偏差的平方根，再给标准差设置下界。每个候选的标准化权重广播到其所有参数坐标，对候选轴求和并除以候选数。最大化奖励时使用加号。

`noise` 是 epsilon，而非 sigma 乘 epsilon。当前约定已将 sigma 的倒数吸收进 alpha，再乘或除一次会改变优化器。标准化奖励也不是 softmax 或排名。

本题要求所有观察值和参数更新都脱离梯度图，避免图沿 rollout 或历史迭代累积。常数奖励（包括单个候选）必须得到有限的全零权重。当标准差下界未触发时，奖励正比例缩放和平移不改变结果；下界生效时不保证这一性质。

小实验使用真实候选奖励和已知最优点。0.08 阈值在种子 42 的参考距离 0.01254 附近留有余量，不代表普遍收敛保证，也不证明大模型的缩放结论。

来源：[第 3 节 Algorithms 1–2](https://arxiv.org/abs/2509.24372)。逐层随机种子重建和分布式推理不属于本题范围。
