# RT-1 TokenLearner Spatial Pooling

## 1. Exercise goal

RT-1 TokenLearner Spatial Pooling: implement the interfaces below and verify numerical, boundary and experimental behavior.

Isolate visual-token compression with supplied MLP attention logits; omit EfficientNet, the Transformer and physical robots.

## 2. Core equations

$$
Z_{bkc}=\sum_l\operatorname{softmax}_l(S_{blk})X_{blc}.
$$

## 3. From equations to code

- `token_learner_pool(features: Tensor, logits: Tensor) -> Tensor`

Transpose logits to (B,K,L), normalize the last axis, and multiply the original features. Each learned token is a spatial convex combination; normalizing K or pooling normalized features changes the operator.

## 4. Contract and boundaries

Features are (B,L,C), logits (B,L,K); softmax only over spatial L. Return (B,K,C), preserving gradients of both inputs.

Validation helpers are provided. All floating inputs are finite CPU float32/float64; do not mutate inputs. Invalid shape, dtype, range or mask arguments raise `ValueError`.

## 5. Deterministic experiment and visualization

`experiment.py` calls every submitted interface on fixed inputs and records a learning or sampling curve and terminal metrics. T3 states the behavioral thresholds; the visualization uses the same outputs.

The visualization is generated by `viz/gen.py`; T3 runs the same experiment with your functions and records its actual metrics. These are small deterministic teaching results, not a robot benchmark.
