# DeepMimic: 题解与易错点

每个分量先对其所有关节/末端坐标平方求和，再应用论文特定指数系数。四项权重和为1，因此完美匹配奖励为1；相同末端偏差比角速度偏差受到更强惩罚。

每个分量先对其所有关节/末端坐标平方求和，再应用论文特定指数系数。四项权重和为1，因此完美匹配奖励为1；相同末端偏差比角速度偏差受到更强惩罚。

先按公式确定归约轴、有效掩码和梯度路径，再将手算小例与实现逐项比较。测试中的独立预期值不调用参考答案。

## 测试捕获的错误

- End-effector position errors use the angular-velocity scale.
- Pose error averages joints instead of summing them.

## 实验范围

实现姿态、角速度、末端与质心四项模仿奖励；姿态输入为预先计算的四元数测地角误差，不实现PPO、姿态解析或物理仿真。

## 可重复实验记录

31个按误差比例1到0生成的动作候选；2关节、2末端，测量分项奖励，无训练器。要求完美匹配奖励1、初始<0.75、30次严格单调改善且全部在(0,1]。

判题固定seed=42。计算采用CPU float64、显式输入，涉及优化时使用普通梯度更新；不下载数据集或模型权重。原生PyTorch与真实Pyodide/NumPy-WASM执行同一套T0–T3测试。阈值针对本教学实验。
