# π0 Reverse-Time Action Flow

## 1. Exercise goal

π0 Reverse-Time Action Flow: implement the interfaces below and verify numerical, boundary and experimental behavior.

Isolate the official openpi linear flow path and Euler sampling direction; explicit noise/time and a linear velocity regressor replace the VLA action expert.

## 2. Core equations

$$
x_t=t\epsilon+(1-t)a,\quad u=\epsilon-a,\quad x_{t+\Delta t}=x_t+\Delta t\,v_t,\quad \Delta t\le0.
$$

## 3. From equations to code

- `flow_interpolate(actions: Tensor, noise: Tensor, time: Tensor) -> tuple`
- `euler_step(state: Tensor, velocity: Tensor, dt: float) -> Tensor`

Official code parameterizes time from actions to noise, so the target velocity is noise-actions. Negative sampling steps transport noise back to actions. Detach the supervised label, not the interpolated state.

## 4. Contract and boundaries

Actions/noise are (B,H,D), time (B,) in [0,1]. Return interpolated state and detached velocity target; retain state gradients. Euler inputs match shapes, dt is finite and <=0. Noise is t=1 and sampling moves to t=0.

Validation helpers are provided. All floating inputs are finite CPU float32/float64; do not mutate inputs. Invalid shape, dtype, range or mask arguments raise `ValueError`.

## 5. Deterministic experiment and visualization

`experiment.py` calls every submitted interface on fixed inputs and records a learning or sampling curve and terminal metrics. T3 states the behavioral thresholds; the visualization uses the same outputs.

The visualization is generated by `viz/gen.py`; T3 runs the same experiment with your functions and records its actual metrics. These are small deterministic teaching results, not a robot benchmark.
