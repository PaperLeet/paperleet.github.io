# RDT-1B Unified Action Slots and Valid Dimensions

## 1. Exercise goal

Place embodiment-specific actions in unified semantic slots and mask absent execution dimensions.

Isolate unified action placement and final sampling masks using a configurable small slot map, not the complete 128D schema or 1.2B Transformer.

## 2. Core equations

$$
U_{bht}=\sum_j A_{bhj}\,\mathbf1[t=s_j],\quad M_t=\mathbf1[t\in\{s_j\}],\quad A^{exec}=\hat U\odot M.
$$

## 3. From equations to code

- `pack_actions(local: Tensor, slots: list, width: int) -> tuple`
- `mask_actions(actions: Tensor, valid: Tensor) -> Tensor`

Do not compact empty slots: each slot retains its physical meaning. The mask distinguishes absent coordinates and clears invalid denoiser outputs before execution. The released training MSE is not a valid-coordinate masked loss, so this exercise does not substitute that objective.

## 4. Contract and boundaries

Local actions are (B,H,D); slots is a Python list of D distinct integers in [0,width). Return floating (B,H,width) actions and bool (width,) validity. mask_actions accepts a sequence and a (width,) bool mask. Unused slots are zero; preserve action gradients.

Validation helpers are provided. All floating inputs are finite CPU float32/float64; do not mutate inputs. Invalid shape, dtype, range or mask arguments raise `ValueError`.

## 5. Deterministic experiment and visualization

Map three action coordinates into six unified slots and train a six-coordinate constant predictor; unused slots start at nine and the execution mask must always suppress them.

The visualization is generated by `viz/gen.py`; T3 runs the same experiment with your functions and records its actual metrics. These are small deterministic teaching results, not a robot benchmark.
