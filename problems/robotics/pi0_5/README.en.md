# π0.5 Leakage-Free Hybrid Action Attention

## 1. Exercise goal

π0.5 Leakage-Free Hybrid Action Attention: implement the interfaces below and verify numerical, boundary and experimental behavior.

Implement Appendix E / Figure 18 training attention connectivity. Prefix, discrete FAST labels and continuous action-expert contents are supplied; omit model pretraining.

## 2. Core equations

$$
M_{qk}=\begin{cases}k<P&q<P\\k<P\ \lor\ (P\le k\le q)&P\le q<P+F\\k<P\ \lor\ k\ge P+F&q\ge P+F\end{cases},\quad M\leftarrow M\land v_q\land v_k.
$$

## 3. From equations to code

- `hybrid_attention_mask(valid: Tensor, prefix_length: int, fast_length: int) -> Tensor`

Prefix queries see prefix only. FAST queries see prefix and causal FAST tokens. Expert queries see prefix and all expert tokens. FAST carries clean action labels, so expert-to-FAST access leaks the flow-matching target. Mask padding on both query and key axes.

## 4. Contract and boundaries

Valid is bool (B,L), prefix_length>=1, fast_length>=0 and at least one expert token remains. Return bool (B,L,L), rows=query, columns=key. FAST inputs are shifted teacher-forcing tokens and may attend themselves; expert attention is bidirectional but cannot see FAST.

Validation helpers are provided. All floating inputs are finite CPU float32/float64; do not mutate inputs. Invalid shape, dtype, range or mask arguments raise `ValueError`.
