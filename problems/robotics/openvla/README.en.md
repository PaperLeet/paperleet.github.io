# OpenVLA Action Tokens and Quantile Unnormalization

## 1. Exercise goal

OpenVLA Action Tokens and Quantile Unnormalization: implement the interfaces below and verify numerical, boundary and experimental behavior.

Reproduce official ActionTokenizer conventions and action unnormalization without a 7B model. Smaller edge arrays make examples inspectable; the official default has 256 edges and 255 centers.

## 2. Core equations

$$
d=\sum_j\mathbf1[\operatorname{clip}(a,-1,1)\ge e_j],\quad t=V-d,\quad \hat a=(e_i+e_{i+1})/2,\ i=\operatorname{clip}(V-t-1,0,N-2).
$$

## 3. From equations to code

- `encode_actions(actions: Tensor, edges: Tensor, vocab_size: int) -> Tensor`
- `decode_actions(tokens: Tensor, edges: Tensor, vocab_size: int) -> Tensor`
- `unnormalize_actions(actions: Tensor, q01: Tensor, q99: Tensor, mask: Tensor) -> Tensor`

Encoding reverses IDs from the vocabulary end. The official np.digitize right=False convention assigns exact edges to the bin on their right. The maximum edge receives the last code and decoding clips it to the last center. Unnormalization transforms only masked coordinates.

## 4. Contract and boundaries

Actions are any nonempty floating tensor; edges is strictly increasing 1-D with endpoints -1/+1, vocab_size>=number of edges. Tokens are int64 in [0,V); non-action vocabulary IDs clip to endpoint centers on decoding. Unnormalization takes (B,D), q01/q99 (D,) with q99>q01, and bool mask (D,).

Validation helpers are provided. All floating inputs are finite CPU float32/float64; do not mutate inputs. Invalid shape, dtype, range or mask arguments raise `ValueError`.
