# 实现提示

奖励先于本次终止门控。维护 `gamma**t*c_t` 权重，用它计入奖励，再乘 `gamma*(1-d_(t+1))`。循环结束后，用剩余权重乘终点价值。时间维求和，只对 batch 取均值。

actor 梯度包含软存活概率、奖励和终点价值的导数。冻结模型参数仍应允许梯度经过模型输入；对预测状态、终止概率或终点价值 detach 都会切断解析策略梯度的一部分。

critic 回归的边界相反：先从已冻结的奖励、终止概率和价值计算目标，再拟合当前价值。lambda 混合项必须用 `V_(t+1)`，不是 `V_t`。lambda 为一时，递推展开等于软存活加权回报，可用作独立的一致性检查。

一维策略实验验证固定动力学中的反向传播。原方法还需要根据仿真转移学习世界模型，并使用人形运动跟踪奖励；这些部分不属于本题的回报核心。
