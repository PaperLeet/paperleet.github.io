# 实现说明

对每个已结束域，先用其自身的平方位移加 xi 归一化重要性，再跨域求和。先累加位移再平方会引入域间抵消；对历史求均值会随着历史增长削弱约束，不符合式 (3)。

正则梯度为 `2*strength*factor*(prompt-anchor)`，没有 EWC 约定中的二分之一。因子与锚点都是历史记录，必须冻结。提示叠加中，共享画布的梯度跨图像相加，图像自身的梯度仍相互独立。不要为显示范围裁剪提示后的像素。

合成目标为 `0.5*||p-[1,-1]||² + strength*4*p0²`，驻点为 `p0=1/(1+8*strength)`、`p1=-1`。测试用这个独立解析解检查真实 SGD 轨迹，而不是比较两份相同参考公式。强度 1 的最终数据损失约 0.3950617284；无正则时小于 1e-8。

原文式 (4)–(6) 周围的提示符号存在不一致。本题采用文字中的角色分配：约束域无关提示，不对完整训练流程的梯度路由作额外推断，也不实现原始的两项一致性目标。

来源：[Method 式 (1)、(3)、(4)](https://arxiv.org/abs/2212.04145)、[AAAI 论文页](https://ojs.aaai.org/index.php/AAAI/article/view/25922)。
