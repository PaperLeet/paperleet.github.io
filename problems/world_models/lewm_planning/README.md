# LeWM 潜在空间 CEM 规划

[LeWorldModel §3.2 与附录 B](https://arxiv.org/html/2603.19312v2) 用冻结的世界模型预测不同动作序列的结果。交叉熵方法（CEM）反复采样计划，选择低代价候选，再根据这些精英样本重估高斯采样分布。

## 实现要求

### 返回值要求

#### `terminal_cost` (需实现)

返回一个浮点 `Tensor` `[N]`，为 rollout `[N,H,D]` 中的每个候选给出一个代价；H 为预测时域，D 为潜在维度。仅对末状态的 D 个平方误差求和，不归约时域或候选，不除以 D。保持 rollout dtype/device 和输入值。本采样规划题不规定梯度或 detach 行为。

#### `cem_refit` (需实现)

按顺序返回 `(mean, variance, elite_indices)`，恰好三个 Tensor。对 candidates `[N,H,A]` 与 K=`num_elites`，mean、总体方差 variance 均为浮点 `[H,A]`，保持候选 dtype/device；elite_indices 是同 device 的 int64 `[K]`，按代价升序、并列时原索引升序排列。只归约 K 个 elite；返回方差（K=1 时为零）而非标准差。不修改输入，本题不规定梯度或 detach 行为。

#### `_float_tensor` (已提供)

已提供校验函数：x 是秩为 ndim 的有限、非空 float32/float64 Tensor时返回 Python `None`；被校验条件不满足时抛出 `ValueError`。不修改输入，也不返回变换后的 Tensor。

### 公式与约定

实现决定候选优劣与下一轮分布的两个内核：

| 函数 | 输入 | 输出 |
|---|---|---|
| `terminal_cost(rollouts, goal)` | 潜在轨迹 `(N,H,D)`、目标 `(D,)` | 每条候选的代价 `(N,)` |
| `cem_refit(candidates, costs, num_elites)` | 动作 `(N,H,A)`、代价 `(N,)`、整数 `1<=K<=N` | 均值 `(H,A)`、方差 `(H,A)`、精英索引 `(K,)` |

使用论文的**终态平方 L2 距离**：

$$J_i=\sum_d(\hat z_{i,H,d}-z_{goal,d})^2.$$

中间状态不参与代价；特征维平方误差取和，不取平均。输入轨迹不含初始状态，至少包含一次预测。

选择 K 个最低代价的候选；代价相同时，原始索引小的优先，即稳定升序排列。对每个动作坐标独立估计：

$$\mu_{h,a}=\frac1K\sum_{i\in E}u_{i,h,a},\qquad v_{h,a}=\frac1K\sum_{i\in E}(u_{i,h,a}-\mu_{h,a})^2.$$

返回**方差**而非标准差，采样器会对它开平方。本题固定使用对角高斯极大似然约定，分母为 K，单个精英的方差为零。`cem_refit` 内不要额外加入方差下限、动量、裁剪或跨时间协方差。

所有张量为有限、非空且类型设备一致的 float32/float64。不要修改输入，starter 已提供检查。这个零阶采样规划器不要求梯度接口。

例如单步候选动作 `[-1,1,3]`、代价 `[4,0,1]`、`K=2`，精英索引为 `[1,2]`，均值为 `2`，方差为 `1`。
