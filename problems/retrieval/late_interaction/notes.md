# 常见坑点

按每个 token 归一化，不是把整个文档展平后归一化。在文档 token 维取 max，在查询 token 维求 sum；均值池化、查询证据取平均、未归一化内积都是不同的打分规则。

零 padding 会超过负的真实匹配，必须在 max 前排除。全遮挡文档没有候选，先保证计算与梯度有限，再设置无效文档分数。不存在的查询位置贡献零，但原版查询增强的 `[MASK]` 向量是有效编码位置，不能自动删除。

精确平局按本题规定将梯度送给第一个有效最大值。不要 detach 文档向量：离线存储文档表示不代表训练时不更新文档编码器。正比例缩放不变性要求范数仍高于 epsilon。

稳定的成对目标依赖“负分减正分”。共享平移会抵消，增加正样本分数应降低损失，极端分差不能溢出。测试用独立标量有限差分验证两侧编码的梯度，也检查两侧分数的梯度。

120 步实验只优化很小的查询向量，文档固定为合成数据。Recall@1 和均值池化碰撞只用于教学，不是 BERT 或 MS MARCO 的复现指标。
