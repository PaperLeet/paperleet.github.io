# 复盘：因果推荐与目标 mask

- 当前位置是已观察输入，故保留对角线。隐藏的是未来，不能写成严格下三角。
- Query 与 key 都要去掉 padding。只在输出最后乘零并不能证明 key 没有干扰真实 query。
- 输入历史和下一物品目标是不同对象；训练损失必须根据目标 ID 去掉 padding。
- 两个二元项不是只依赖分差的成对排序目标。给正负 logits 同时加常数通常会改变本题损失。
- 先屏蔽无效 logits，再做 softplus，避免 `0 * NaN`。全空目标的零也要保留两条梯度路径。
- 训练位置准确率只能说明依赖历史的合成任务被拟合；真实推荐仍需 held-out 数据、候选过滤与规范指标。
