# BPR-MF：哪些细节决定了训练方向

1. **未观察不等于负标签。** mask 只定义可参与相对比较的物品。用户甲已经交互的所有物品都要排除；用户乙的历史不能替甲排除物品。
2. **方向和求和轴。** 优化的是 `-log sigmoid(用户·正物品 - 用户·未观察物品)`。内积对特征求和，数据项对三元组取平均。把符号写反会训练出反向排序；取特征均值会引入维度依赖的温度。
3. **两张表的梯度。** 设 `a = sigmoid(-margin) / B`，单个三元组的数据梯度为 `d用户=-a*(正物品-负物品)`、`d正物品=-a*用户`、`d负物品=a*用户`。相同 ID 的贡献相加，不能 detach 正样本分支。
4. **全表先验。** 本题正则梯度是每个参数的 `2*l2*参数`。只惩罚抽取行会重复计算频繁 ID，并漏掉未选中行。这里约定全表先验，和常见的按 sampled row／角色写的更新不能混用系数。
5. **空 batch 与稳定性。** 数据项为空仍需保留可微零和先验。用 `softplus(-margin)` 或等价 log-sigmoid，极端负 margin 才不会饱和成 `log(0)`。

实验中的全局物品顺序上限由相反偏好的对数给出。正确率突破这个上限说明模型利用了用户条件；它只证明合成训练任务的行为。完整 LearnBPR 的采样、正则设置和数据评估不在本题范围内。
