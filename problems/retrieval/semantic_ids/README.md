# TIGER：残差量化与语义 ID

## 1. 问题

TIGER 把物品内容编码成语义 ID，再用序列模型生成 ID 来召回物品。本题只实现编码器之后的**冻结残差量化**和碰撞消解。输入已经是 latent，码本已经给定；无需训练 RQ-VAE、下载数据或使用 GPU。完成本题后可继续模块 65，生成这些 ID 并查回物品。

## 2. 核心公式

令 $r_0=z$。第 $d$ 级使用自己的码本 $C_d$：

$$c_d=\arg\min_j\|r_d-C_d[j]\|_2^2,\quad r_{d+1}=r_d-C_d[c_d],\quad \hat z=\sum_d C_d[c_d].$$

论文 §3.1 给出残差量化；§4 为共享相同语义元组的物品附加不同的第四个 codeword。本题推广到任意正整数级数，并明确碰撞序号按输入行首次出现顺序分配。

## 3. 公式到代码

实现 `residual_quantize(latents, codebooks)`，返回码索引与重建向量；实现 `resolve_collisions(codes)`，追加组内序号。例如 `[[7,1,4],[8,2,0],[7,1,4]]` 变成 `[[7,1,4,0],[8,2,0,0],[7,1,4,1]]`。

手算：`z=4.8`，第一层码本 `[0,4,-4]` 选 4，剩余 .8；第二层 `[0,.75,-.75]` 选 .75，最终重建 4.75，索引 `[1,1]`。不是每一级都重新量化原始 z。

## 4. 本题约定

- `latents[B,D]`、`codebooks[L,K,D]`：有限 CPU float32/float64，dtype 相同；B 可为 0，L/K/D 至少 1。支持非连续输入。
- 每一级独立选择最近的码向量，精确相等的距离取最小索引。输出 codes 为 int64 `[B,L]`，重建 `[B,D]` 保持输入 dtype/device，二者均不带梯度，禁止修改输入。
- `resolve_collisions` 输入为非负 CPU int64 `[B,L]`，返回 `[B,L+1]`。对每个完整元组独立计数，后缀依次 0、1、2；单独出现的元组也追加 0。禁止修改输入。
- 输入满足上述约定，无需做参数合法性检查。碰撞序号是本题固定的可复现规则，论文没有规定物品排序。增删目录后重新编号可能改变后缀，真实服务应持久化物品 ID 映射。
- 原论文使用三层、每层 256 个 32 维向量，并训练 encoder/decoder/codebooks。本题只测冻结编码，不实现 straight-through 梯度、重建训练损失或原论文指标。

## 5. 交互图

Lab 以 8 个二维物品和 3 层、每层 5 个向量演示重建误差与碰撞后缀。**我的运行结果**来自当前提交的两个函数，参考实验单独展示。标量距离计算独立核对码索引和重建，后缀应得到 8 个不同的完整 ID。包含零向量的本例误差随深度不增加；任意码本不保证这一性质。
