# 常见坑点

beam 的分数是累计的条件 log-probability，不能只保留最后一步，也不能用未归一化 logits 跨前缀比较。给每个前缀的 logits 加不同常数，应保持解码结果不变。

扩展所有保留前缀，再全局截断。先对每个前缀贪心选一个 token 会漏掉竞争序列。同分按完整 tuple 排序，避免排序偶然性。

过滤无效完整 ID 与重复物品后，再取 k；先截断会少返回合法物品。保留原分数，不能只在目录 token 上重新归一化。返回目录行号而非 token 或 beam 行号。

原论文允许生成无效 ID，§4.5 的过滤与前缀匹配扩展应区分。穷举只用于 625 个序列的教学 oracle；大目录需要实际性能与相关性评估。有限 beam 是近似，不能承诺单调提升。
