## Source notes

- ByteDance embeds its favicon as a PNG data URL in its official homepage. `bytedance.png` contains the decoded original PNG bytes; the source link points to that page.
- Alibaba Group’s favicon URL ends in `.ico`, but the server returns a JPEG. It is saved unchanged as `alibaba.jpg` to match its actual format.
- OpenAI and Microsoft use the icons published on their official developer and Microsoft Learn sites. Tesla uses the favicon on its official China site.
- Meta, Anthropic, Kuaishou, and Meituan link to the listed CDN assets from their official sites.
- Brown’s image is its official Apple touch icon. Berkeley’s favicon is served by its official brand site.
